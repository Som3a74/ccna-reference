خدمات NAT و PAT

نبذة سريعة

خدمة NAT (Network Address Translation) بتترجم الأيبيهات الخاصة (Private) لأيبيهات عامة (Public) عشان الأجهزة تقدر تطلع إنترنت. في CCNA عندنا نوعين مهمين جداً في العملي: Static NAT (بتربط IP داخلي بـ IP خارجي واحد لواحد، وغالباً بيتعمل للسيرفرات)، و PAT أو NAT Overload (بيخلي كل أجهزة الشركة تطلع إنترنت بـ IP خارجي واحد بس عن طريق أرقام البورتات).

إعداد سريع (انسخ والصق)

إعداد PAT (Overload) عشان تخلي شبكة داخلية تطلع إنترنت باستخدام الـ IP الخاص بفتحة الـ WAN:

! 1. تحديد الفتحات الداخلية والخارجية
interface g0/0
 ip nat inside
interface g0/1
 ip nat outside

! 2. عمل Access List تحدد مين مسموح له يطلع إنترنت
access-list 1 permit 192.168.1.0 0.0.0.255

! 3. تشغيل الـ PAT وربطه بالفتحة الخارجية
ip nat inside source list 1 interface g0/1 overload

الإعداد خطوة بخطوة

ip nat inside / outside Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ip nat inside
ip nat outside

الشرح: أهم خطوة تنساها في الامتحان! لازم تدخل على الفتحة اللي واصلة بالشبكة الداخلية (LAN) وتكتب ip nat inside، وتدخل على الفتحة اللي واصلة بالإنترنت (WAN) وتكتب ip nat outside عشان الراوتر يعرف هيترجم من فين لفين.

ip nat inside source static Global config

Router(config)# Exam PT ✔

الصيغة:

ip nat inside source static <local-ip> <global-ip>

إيه اللي بنحطه مكان القيم:

  • <local-ip> = الـ IP الداخلي الخاص (Inside Local) زي 192.168.1.10.
  • <global-ip> = الـ IP العام اللي اشتريته من مزود الخدمة (Inside Global) زي 200.1.1.5.

الشرح: الـ Static NAT بيعمل ربط 1-to-1. أي حد على الإنترنت هيكتب 200.1.1.5 الراوتر هيحوله فوراً للسيرفر الداخلي 192.168.1.10. دي خطوة أساسية لو عندك Web Server عايز تطلعه للعالم.

ip nat inside source list (PAT) Global config

Router(config)# Exam PT ✔

الصيغة:

ip nat inside source list <acl-number> interface <exit-interface> overload

الشرح: ده الـ PAT (Port Address Translation). بيسمح لأجهزة كتير تطلع إنترنت بـ IP عام واحد فقط (وهو الـ IP الموجود على الفتحة interface اللي هتكتبها). لازم الأول تعمل access-list تحدد فيها الأيبيهات الداخلية المسموح لها تطلع إنترنت، وبعدين تكتب الأمر ده وتربطهم ببعض، ومتنساش كلمة overload في الآخر، من غيرها مش هيشتغل كـ PAT!

أوامر التحقق

show ip nat translations Privileged EXEC

Router# Exam PT ✔

الشرح: بيعرض جدول الترجمة الحالي، وبيوضح كل IP داخلي واخد بورت كام وطالع يكلم مين على الإنترنت.

Router# show ip nat translations
Pro Inside global      Inside local       Outside local      Outside global
tcp 200.1.1.2:1024     192.168.1.10:1024  8.8.8.8:80         8.8.8.8:80
tcp 200.1.1.2:1025     192.168.1.15:1025  8.8.8.8:80         8.8.8.8:80
--- 200.1.1.5          192.168.1.100      ---                ---

ملاحظة: السطر الأخير اللي مفيهوش بورتات ده بتاع الـ Static NAT، والباقي ده الـ PAT.

الشرح: بيمسح كل الترجمات الحالية من الجدول (ما عدا الـ Static). مفيد لو غيرت الإعدادات وعايز الراوتر يبدأ من جديد بدون ما تعمل ريستارت.

فحص الأعطال (Troubleshooting)

  • الإنترنت مش شغال رغم إعداد الـ PAT: تأكد من 3 حاجات:
    1. هل نسيت أو عكست الـ ip nat inside والـ ip nat outside على الفتحات؟
    2. هل الـ Access List اللي مستخدمها بتسمح بشبكتك فعلاً؟ (جرب show access-lists).
    3. هل نسيت كلمة overload في نهاية الأمر؟

أخطاء شائعة وفخاخ الامتحان

  • مصطلحات الـ NAT للامتحان: سيسكو بتحب تلعب بالألفاظ دي جداً:
    • Inside Local: الـ IP الداخلي الخاص بالجهاز بتاعك (192.168.x.x).
    • Inside Global: الـ IP العام اللي الراوتر بيترجمك ليه عشان تطلع إنترنت.
    • Outside Local / Outside Global: الـ IP بتاع الموقع اللي بتزوره (في الغالب هما الاتنين واحد).

جدول مختصر

Command الوظيفة (Purpose)
ip nat inside تحديد الفتحة الداخلية للـ NAT.
ip nat outside تحديد الفتحة الخارجية للـ NAT.
ip nat inside source static [local] [global] إعداد مسار NAT ثابت 1-to-1 لسيرفر.
ip nat inside source list [acl] interface [int] overload تفعيل الـ PAT لشبكة كاملة عشان تطلع بـ IP الفتحة دي.
show ip nat translations عرض جدول الأيبيهات والبورتات المترجمة.
