خدمات DHCP و DNS

نبذة سريعة

خدمة DHCP بتوزع أيبيهات أوتوماتيك على الأجهزة في الشبكة. في الامتحان، سيسكو بتركز جداً على إعداد الراوتر كـ DHCP Client (عشان ياخد IP من مزود الخدمة) وكـ DHCP Relay (عشان يوصل رسايل البرودكاست بتاعة الأجهزة لسيرفر DHCP موجود في شبكة تانية). كمان إعداد الـ DNS مهم عشان الراوتر يقدر يفهم الأسماء زي cisco.com بدل الأرقام.

إعداد سريع (انسخ والصق)

تفعيل راوتر ليكون DHCP Server، وتفعيل منفذ ليعمل كـ DHCP Client:

! إعداد سيرفر DHCP واستثناء بعض الأيبيهات
ip dhcp excluded-address 192.168.1.1 192.168.1.10
ip dhcp pool LAN-POOL
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8

! إعداد منفذ ليأخذ IP أوتوماتيك
interface g0/1
 ip address dhcp

الإعداد خطوة بخطوة

ip dhcp excluded-address Global config

Router(config)# Exam PT ✔

الصيغة:

ip dhcp excluded-address <low-ip> [high-ip]

الشرح: قبل ما تعمل البول (Pool) وتوزع أيبيهات، لازم تستثني الأيبيهات الثابتة في شبكتك (زي عنوان الراوتر نفسه، أو السيرفرات، أو الطابعات) عشان الراوتر ميوزعهاش لجهاز تاني ويحصل IP Conflict.

ip dhcp pool Global config

Router(config)# Exam PT ✔

الصيغة:

ip dhcp pool <pool-name>
 network <network-ip> <subnet-mask>
 default-router <gateway-ip>
 dns-server <dns-ip>

الشرح: بيكريت وعاء (Pool) يوزع منه. network بيحدد الرينج والماسك. default-router هو عنوان البوابة اللي الأجهزة هتخرج منها (غالباً الـ IP بتاع الراوتر نفسه). dns-server بيحدد سيرفرات الـ DNS.

ip helper-address Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ip helper-address <dhcp-server-ip>

الشرح: أهم أمر في الامتحان! لو الأجهزة في شبكة (مثلاً VLAN 10) وسيرفر الـ DHCP في شبكة تانية، الراوتر مستحيل يعدي رسالة الـ Broadcast اللي الجهاز بيبعتها (DHCP Discover). الأمر ده بيتحط على منفذ الراوتر (أو الـ SVI) اللي مواجه للأجهزة، وبيقول للراوتر: "أي رسالة برودكاست للـ DHCP تجيلك هنا، حولها لـ Unicast وابعتها للـ IP ده".

ip address dhcp Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ip address dhcp

الشرح: بيخلي الفتحة دي تشتغل كـ Client وتاخد الـ IP بتاعها أوتوماتيك من راوتر أو سيرفر تاني (غالباً بنستخدمه على الفتحة اللي واصلة بالإنترنت ISP).

ip name-server Global config

Router(config)# PT ✔

الصيغة:

ip name-server <dns-ip>
ip domain-lookup

الشرح: بيعرف الراوتر نفسه مين هو سيرفر الـ DNS اللي يروح يسأله لو كتبنا اسم بدل IP (مثلاً لو كتبنا ping cisco.com).

فحص الأعطال (Troubleshooting)

  • الأجهزة لا تحصل على IP: تأكد من أمر ip helper-address. يجب أن يُكتب على الـ Interface التي تعمل كـ Default Gateway للأجهزة (مثل الـ Subinterface أو ה-SVI)، وليس على الـ Interface المواجهة للسيرفر!
  • تضارب في الأيبيهات (IP Conflicts): بيحصل لو الراوتر وزع IP لجهاز، والـ IP ده كان متثبت يدوياً على جهاز تاني. هيظهرلك رسالة في الـ Log بتقول %DHCPD-4-DECLINE_CONFLICT. الحل إنك تستخدم أمر ip dhcp excluded-address.

أخطاء شائعة وفخاخ الامتحان

  • ترتيب أمر الاستثناء: أمر الـ Exclude بيتكتب في وضع الـ Global Config (Router(config)#) وليس بداخل وضع إعدادات البول! دي بتوقع ناس كتير في العملي.
  • خطأ الطباعة في DNS: لو كتبت أمر غلط في الـ CLI، الراوتر بيحاول يعمل له Broadcast كأنه اسم موقع (Translating "..."...domain server). عشان تلغي الخاصية المزعجة دي بنكتب no ip domain-lookup.

جدول مختصر

Command الوظيفة (Purpose)
ip dhcp excluded-address <ip> استثناء أيبيهات من التوزيع العشوائي.
ip dhcp pool <name> إنشاء صندوق أيبيهات لتوزيعه.
ip helper-address <ip> تحويل رسائل DHCP من شبكة لأخرى (DHCP Relay).
ip address dhcp جعل المنفذ يسحب IP أوتوماتيك من سيرفر.
show ip dhcp binding عرض الأجهزة التي استلمت أيبيهات والـ MAC الخاص بها.
