CCNA Reference

إعدادات اللاب الكاملة (Complete Lab Configurations)

نبذة سريعة

هذه الصفحة هي المحطة الختامية والتطبيقية لمشروع CCNA Reference؛ حيث تجمع كافة المهارات والأوامر التي تعلمناها في سيناريوهات وتوبولوجيات معامل كاملة وجاهزة للنسخ واللصق (Copy & Paste) في برنامج Cisco Packet Tracer أو معامل GNS3 / EVE-NG / CML:

  • لاب 1 (Campus LAN Architecture): شبكة سويتشات مؤسسية متكاملة تشمل VLANs, Trunking, EtherChannel, Rapid-PVST, HSRP, و OSPF.
  • لاب 2 (Edge Router & Services): راوتر حافة الشبكة المتصل بالإنترنت مع NAT/PAT, DHCP Server, وتقوية أمنية شاملة (SSHv2, Hardening, NTP, Syslog, ACLs).
  • لاب 3 (Branch Office VPN): ربط فرعين عبر نفق GRE مشفر بـ IPsec ومفعل عليه توجيه OSPF الديناميكي.

سيناريوهات المعامل المتكاملة

Lab 1: Complete Campus LAN (L2/L3 & HSRP) Enterprise Architecture

Full Lab PT ✔

الإعداد الكامل لسويتش التوزيع الأساسي (Distribution / L3 Switch 1):

! 1. Initial setup and routing enable
hostname DSW1
ip routing

! 2. Create VLANs
vlan 10
 name DATA_USERS
vlan 20
 name VOICE_USERS
vlan 99
 name NATIVE_MGMT

! 3. Configure LACP EtherChannel (Port-Channel 1) to DSW2
interface range GigabitEthernet0/1 - 2
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 channel-group 1 mode active
interface port-channel 1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99

! 4. STP Root Bridge configuration
spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary
spanning-tree vlan 20 root secondary

! 5. SVIs and HSRPv2 default gateway redundancy
interface Vlan10
 ip address 192.168.10.2 255.255.255.0
 standby version 2
 standby 10 ip 192.168.10.1
 standby 10 priority 110
 standby 10 preempt
 no shutdown

interface Vlan20
 ip address 192.168.20.2 255.255.255.0
 standby version 2
 standby 20 ip 192.168.20.1
 standby 20 priority 90
 standby 20 preempt
 no shutdown

! 6. OSPFv2 dynamic routing configuration
router ospf 1
 router-id 1.1.1.1
 auto-cost reference-bandwidth 1000
 passive-interface Vlan10
 passive-interface Vlan20
 network 192.168.10.0 0.0.0.255 area 0
 network 192.168.20.0 0.0.0.255 area 0
 network 10.0.0.0 0.0.0.3 area 0

الإعداد الكامل لسويتش الوصول (Access Switch - ASW1):

hostname ASW1

! 1. Create VLANs
vlan 10
 name DATA_USERS
vlan 20
 name VOICE_USERS
vlan 99
 name NATIVE_MGMT

! 2. Uplink trunk ports with DTP disabled
interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk native vlan 99
 switchport nonegotiate

! 3. Access user ports with Port Security and BPDU Guard
interface range FastEthernet0/1 - 24
 switchport mode access
 switchport access vlan 10
 switchport voice vlan 20
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation restrict

Lab 2: Edge Router (NAT, DHCP & Security) Internet Gateway

Full Lab PT ✔

الإعداد الشامل لراوتر الحافة (Edge Router - R1):

hostname R1-EDGE

! 1. Password security and local admin user
enable algorithm-type sha256 secret CiscoSuperSecret#2026
service password-encryption
security passwords min-length 10
username netadmin privilege 15 secret AdminPass#2026

! 2. Brute-force login protection
login block-for 120 attempts 3 within 60
login on-failure log
login on-success log

! 3. Secure VTY with SSHv2 only
ip domain-name enterprise.local
crypto key generate rsa modulus 2048
ip ssh version 2
ip ssh time-out 60
line con 0
 exec-timeout 5 0
 logging synchronous
line vty 0 4
 exec-timeout 5 0
 transport input ssh
 login local
 logging synchronous
line aux 0
 no exec

! 4. Security warning banner
banner motd ^
*************************************************************
* WARNING: Authorized Personnel Only. Activities Monitored. *
*************************************************************
^

! 5. Interface configuration and NAT direction
interface GigabitEthernet0/0
 description LAN Interface
 ip address 10.0.0.1 255.255.255.252
 ip nat inside
 no shutdown

interface GigabitEthernet0/1
 description WAN Interface to ISP
 ip address 203.0.113.2 255.255.255.248
 ip nat outside
 no shutdown

! 6. Default route to ISP gateway
ip route 0.0.0.0 0.0.0.0 203.0.113.1

! 7. DHCP server for LAN clients
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp pool LAN_POOL
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8 1.1.1.1

! 8. NAT Overload (PAT) configuration
access-list 1 permit 192.168.10.0 0.0.0.255
access-list 1 permit 192.168.20.0 0.0.0.255
ip nat inside source list 1 interface GigabitEthernet0/1 overload

! 9. NTP, Syslog and SNMP monitoring services
clock timezone EEST 2 0
ntp server 203.0.113.5 prefer
service timestamps log datetime msec
logging buffered 64000 informational
logging host 192.168.10.50
logging trap warnings
snmp-server community NetMonitorRO RO

Lab 3: Branch Office GRE over IPsec VPN Secure Multi-site

Full Lab PT ✔

إعداد نفق الـ VPN المشفر بين المقر الرئيسي (HQ) والفرع (Branch):

! [R1-HQ Router Configuration]
! 1. IKE Phase 1 ISAKMP policy
crypto isakmp policy 10
 encr aes 256
 hash sha256
 authentication pre-share
 group 14
 lifetime 86400
crypto isakmp key VpnSecretKey#2026 address 198.51.100.2

! 2. IKE Phase 2 IPsec transform-set and profile
crypto ipsec transform-set TS-AES-SHA esp-aes 256 esp-sha256-hmac
 mode transport
crypto ipsec profile IPSEC-TUNNEL-PROFILE
 set transform-set TS-AES-SHA

! 3. GRE Tunnel interface with IPsec protection
interface Tunnel0
 ip address 172.16.0.1 255.255.255.252
 tunnel source GigabitEthernet0/1
 tunnel destination 198.51.100.2
 tunnel protection ipsec profile IPSEC-TUNNEL-PROFILE

! 4. OSPF routing over tunnel
router ospf 1
 network 172.16.0.0 0.0.0.3 area 0
 network 10.1.0.0 0.0.255.255 area 0
