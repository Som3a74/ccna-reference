Special IP Ranges (RFC 1918 & IPv6) IP Addressing

Exam Core IP Ranges

1. عناوين IPv4 الخاصة (RFC 1918 Private Addresses):

  • Class A: من 10.0.0.0 إلى 10.255.255.255 (قناع /8).
  • Class B: من 172.16.0.0 إلى 172.31.255.255 (قناع /12 - 16 شبكة).
  • Class C: من 192.168.0.0 إلى 192.168.255.255 (قناع /16 - 256 شبكة).
  • APIPA (Link-Local): من 169.254.0.0 إلى 169.254.255.255 (عند فشل DHCP).
  • Loopback: 127.0.0.0/8 (للاختبار الداخلي).

2. أنواع عناوين IPv6 الخاصة للامتحان:

  • Global Unicast (GUA): تبدأ بـ 2000::/3 (عناوين عامة قابلة للتوجيه في الإنترنت).
  • Unique Local (ULA): تبدأ بـ fc00::/7 (خاصة بالشبكات الداخلية - بديل RFC 1918).
  • Link-Local (LLA): تبدأ بـ fe80::/10 (خاصة بالاتصال على نفس الرابط، إلزامية لكل منفذ).
  • Multicast: تبدأ بـ ff00::/8:
    • ff02::1 = كل الأجهزة (All Nodes).
    • ff02::2 = كل الراوترات (All Routers).
    • ff02::5 = كل راوترات OSPFv3.
    • ff02::6 = راوترات الـ DR/BDR في OSPFv3.
  • Loopback: ::1/128.
  • Unspecified: ::/128.

OSPF Adjacency & STP Port States Protocol Lifecycle

Exam Core States

1. مراحل جيرة OSPF بالترتيب الزمني:

  1. Down: لا توجد أي رسائل Hello مستلمة.
  2. Init: استلم الراوتر حزمة Hello لكن اسمه (Router-ID) غير موجود فيها بعد.
  3. 2-Way: رأى الراوتر اسمه في رسالة Hello الطرف الآخر (تم تأكيد الاتصال ثنائي الاتجاه، ويتم انتخاب الـ DR/BDR في هذه المرحلة).
  4. ExStart: تحديد السيد والتابع (Master / Slave) واختيار رقم التسلسل الابتدائي للـ DBD.
  5. Exchange: تبادل ملخصات قاعدة البيانات (DBD Packets).
  6. Loading: طلب التفاصيل الناقصة عبر LSR واستلام الرد بـ LSU وإرسال تأكيد LSAck.
  7. Full: اكتمال المزامنة التامة والتطابق الكامل لقاعدة بيانات الـ LSDB.

2. مقارنة حالات منافذ STP (802.1D) مقابل Rapid-PVST (802.1w):
