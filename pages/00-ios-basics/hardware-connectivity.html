CCNA Reference

فحص الأجهزة، الاتصال، والمنافذ

نبذة سريعة

الصفحة دي بتجمع الأوامر الخاصة بالتعامل مع الهاردوير (CPU، مروحة، حرارة)، وأدوات اختبار الشبكة زي الـ Ping والـ Traceroute، بالإضافة لأوامر إدارة المنافذ (Interfaces) الفيزيائية ومراقبة حالتها واكتشاف أخطاء الكابلات.

إعداد سريع (انسخ والصق)

عشان تشغل مجموعة منافذ وتظبط سرعتهم وتلغي قفلهم:

interface range g0/1 - 4
 speed 1000
 duplex full
 mdix auto
 no shutdown

الإعداد خطوة بخطوة

1. فحص الهاردوير والموارد

show inventory Privileged EXEC

Router# Exam PT ✔

الصيغة:

show inventory

الشرح: بيعرض كل القطع المادية المتركبة في الجهاز زي الموديولات والـ SFP، وأهم حاجة بيجيب الأرقام المسلسلة (Serial Numbers) بتاعتها، واللي بتحتاجها جداً لو بتفتح تذكرة صيانة مع سيسكو (TAC).

مثال:

Router# show inventory
NAME: "Chassis", DESCR: "Cisco 2901 Integrated Services Router"
PID: CISCO2901/K9        , VID: V01, SN: FTX15248XYZ

show environment Privileged EXEC

Router# Exam PT Partial

الصيغة:

show environment [all | temperature]

الشرح: بيعرض حالة الباور سبلاي، المراوح، ودرجات الحرارة. أمر مهم جداً لو السويتش في مكان حر ومحتاج تطمن إنه مبيسيحش.

show processes cpu / memory Privileged EXEC

Router# Exam PT ✔

الصيغة:

show processes cpu [sorted]
show memory

الشرح: بيوريك استهلاك المعالج (الـ CPU) والرامات. sorted بيجيبلك أكتر العمليات سحباً للمعالج في الأول. لو لقيت المعالج 99%، ده بيفسر ليه الشبكة واقعة أو بطيئة.

show tech-support Privileged EXEC

Router# Exam PT ✖

الصيغة:

show tech-support

الشرح: بيعمل تفريغ لآلاف السطور من كل أوامر الفحص الممكنة ورا بعض. ده الأمر اللي بيطلبه منك مهندس الدعم الفني بتاع سيسكو عشان يحلل المشكلة. بياخد دقايق عشان يخلص وممكن يتقل الجهاز شوية.

2. أدوات الاتصال والتتبع (Connectivity Tools)

ping (Basic & Extended) Privileged EXEC

Router# Exam PT ✔

الصيغة:

ping <ip-address>
ping

إيه اللي بنحطه مكان القيم:

  • <ip-address> = عنوان الـ IP اللي عايز تختبر الوصول ليه.

الشرح: الـ Ping العادي بيبعت 5 رسايل حجمهم 100 بايت وبيخرجوا من أقرب منفذ للوجهة. لو كتبت ping وضغطت Enter من غير أرقام، هتدخل في الـ Extended Ping، وده بيسألك سلسلة أسئلة تقدر تغير منها حجم الرسالة وعددها، وأهم حاجة إنك تغير الـ Source IP عشان تختبر الوصول كأنك شبكة تانية.

مثال للـ Extended Ping:

R1# ping
Protocol [ip]: 
Target IP address: 192.168.20.1
Repeat count [5]: 100
Datagram size [100]: 
Timeout in seconds [2]: 
Extended commands [n]: y
Source address or interface: 10.0.12.1
Type of service [0]:

traceroute Privileged EXEC

Router# Exam PT ✔

الصيغة:

traceroute <ip-address>

الشرح: بيتتبع المسار اللي بتمشي فيه الداتا لحد الوجهة، وبيطبع كل راوتر (Hop) بيعدي عليه. مفيد جداً عشان تعرف الداتا بتقف عند مين بالظبط.

انتبه: في أجهزة سيسكو بيكتب traceroute، لكن في أجهزة الويندوز الأمر بيكون tracert.

telnet / ssh Privileged EXEC

Router# Exam PT ✔

الصيغة:

telnet <ip-address>
ssh -l <username> <ip-address>

الشرح: عشان تدخل على جهاز تاني من جوة الراوتر بتاعك.

مثال:

R1# ssh -l admin 192.168.10.2

terminal monitor Privileged EXEC

Router# Exam PT ✔

الصيغة:

terminal monitor

الشرح: افتراضياً، رسايل النظام والـ Debug بتطبع على شاشة الكونسول بس. لو إنت داخل عن طريق SSH أو Telnet (يعني VTY)، مش هتشوف أي رسايل بتطلع. الأمر ده بيخلي الراوتر يبعت الرسايل دي لجلستك الحالية.

debug Privileged EXEC

Router# Exam PT ✔

الصيغة:

debug <protocol>
undebug all

الشرح: بيشغل مراقبة حية لحظية لبروتوكول معين (مثلاً debug ip ospf hello)، وبيطبعلك كل رسالة بتتبعت أو تستقبل في وقتها. أداة خرافية لاكتشاف الأعطال العميقة.

انتبه: إياك تكتب debug all على راوتر في شغل حقيقي! ده هيطبع كل فتفوتة بتحصل على الجهاز، المعالج هيوصل 100% والجهاز هيقف عن العمل. عشان توقف أي debug شغال، اكتب undebug all (أو un all) فوراً.

3. إدارة المنافذ (Interfaces)

interface / range Global config

Router(config)# Exam PT ✔

الصيغة:

interface <type><number>
interface range <type><number> - <number>

إيه اللي بنحطه مكان القيم:

  • <type> = نوع المنفذ (FastEthernet, GigabitEthernet, Serial).
  • <number> = رقم المنفذ (مثلًا: 0/1). وفي حالة הـ range بنحط مسافة قبل وبعد علامة الطرح (مثلًا: g0/1 - 4).

مثال:

SW1(config)# interface range f0/1 - 24
SW1(config-if-range)# shutdown

shutdown / no shutdown Interface config

Router(config-if)# Exam PT ✔

الصيغة:

shutdown
no shutdown

الشرح: أمر shutdown بيقفل المنفذ إدارياً (بتظهر حالته administratively down). أمر no shutdown بيشغله. الرواتر بتيجي وكل منافذها مقفولة، السويتشات بتيجي ومنافذها مفتوحة.

speed / duplex / mdix auto Interface config

Router(config-if)# Exam PT ✔

الصيغة:

speed { 10 | 100 | 1000 | auto }
duplex { half | full | auto }
mdix auto

الشرح: افتراضياً كل المنافذ معمولة auto وبتتفاوض مع الجهاز اللي قدامها. أمر mdix auto بيخلي المنفذ يعدل نفسه لو ركبت كابل غلط (Straight مكان Crossover أو العكس)، الخاصية دي شغالة تلقائي في السويتشات الحديثة.

errdisable recovery Global config

Router(config)# Exam PT ✔

الصيغة:

errdisable recovery cause { all | psecure-violation | bpduguard | ... }
errdisable recovery interval <seconds>

الشرح: لو بورت اتقفل بسبب مشكلة حماية (الـ state بقت err-disabled)، الطريقة اليدوية عشان ترجعه هي إنك تعمله shutdown وبعدين no shutdown. الأوامر دي بتخلي السويتش يعمله ريستارت لوحده بعد فترة معينة (الافتراضي 300 ثانية).

أوامر التحقق

1. show ip interface brief

الأمر الذهبي! بيجيبلك لستة بكل المنافذ، الـ IP بتاعها، وحالتها (مفتوحة ولا مقفولة ولا الكابل مقطوع).

R1# show ip interface brief
Interface              IP-Address      OK? Method Status                Protocol
GigabitEthernet0/0     192.168.10.1    YES manual up                    up
GigabitEthernet0/1     unassigned      YES unset  administratively down down

2. show interfaces status

أمر خاص بالسويتشات، بيوريك حالة المنفذ، الـ VLAN اللي هو فيها، السرعة، والـ Duplex في جدول شيك جداً.

SW1# show interfaces status
Port      Name               Status       Vlan       Duplex  Speed Type
Fa0/1                        connected    10         a-full  a-100 10/100BaseTX
Fa0/2                        err-disabled 1          auto    auto  10/100BaseTX

3. show interfaces

أمر طويل جداً بس بنحتاجه عشان نقرا أخطاء الكابلات والتشويش:

فحص الأعطال ومؤشرات الأخطاء

أشكال نتائج الـ Ping

  • ! : نجاح. الرد وصل.
  • . : فشل (Timeout). مفيش رد.
  • U : الجهاز أو المسار غير موجود (Unreachable). غالباً مشكلة في الـ Routing.

قراءة عدادات الأخطاء (Counters Errors)

  • Runts: فريم أصغر من 64 بايت (غالباً مشكلة تصادم Collisions).
  • Giants: فريم أكبر من 1518 بايت (غالباً مشكلة في إعدادات كارت الشبكة أو الـ VLAN tag).
  • CRC: الداتا وصلت متكسرة أو متشوشة. بنسبة 90% كابل بايظ أو تشويش مغناطيسي (EMI).
  • Late Collisions: تصادم حصل متأخر، ده معناه إن الكابل أطول من المسموح بيه (أكتر من 100 متر)، أو فيه Duplex Mismatch (طرف Half وطرف Full).

مشكلة الـ Duplex Mismatch

لو وصلت جهازين، واحد معمول full duplex والتاني معمول half duplex، الاتصال هيشتغل والـ Ping هيرد، بس لما الداتا تكتر الشبكة هتقع وهتلاقي رسايل زي %CDP-4-DUPLEX_MISMATCH بتظهر باستمرار.

أخطاء شائعة وفخاخ الامتحان

  • تنسى تكتب terminal monitor وإنت داخل SSH وتقعد تكتب debug وتستنى رسايل تطلع ومفيش حاجة تطلع.
  • في السويتشات، لو حطيت سرعة المنفذ speed 100 مثلاً بدل auto، السويتش بيقفل خاصية التخاطب التلقائي (Auto-negotiation)، وده ممكن يعطل الـ Duplex ويخليه ينزل לـ Half غصب عنه لو الطرف التاني لسة Auto.

جدول مختصر

Command الوظيفة (Purpose)
show inventory عرض القطع والسيريال نمبر.
ping / traceroute فحص الوصول وتتبع المسار.
terminal monitor إظهار رسائل الـ syslog والـ debug على شاشة الـ SSH.
debug <protocol> مراقبة حية لحظية للبروتوكول.
show ip interface brief خلاصة حالة المنافذ والـ IP.
show interfaces status عرض الـ Duplex والسرعة والـ VLAN (للسويتشات).
errdisable recovery cause ... إعادة تشغيل المنافذ المعطلة أمنياً بشكل تلقائي.
