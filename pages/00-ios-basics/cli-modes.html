أوضاع CLI والتنقل (CLI Modes)

نبذة سريعة

نظام تشغيل سيسكو (Cisco IOS) بيعتمد على واجهة سطر الأوامر (CLI). الأوامر فيه متقسمة لمستويات أو أوضاع (Modes) هرمية: وضع المستخدم (User EXEC) للمشاهدة البسيطة، وضع الامتيازات (Privileged EXEC) للفحص الكامل والحفظ، ووضع الإعدادات (Global Configuration) اللي منه بتغير في برمجة الراوتر.

إعداد سريع (انسخ والصق)

عشان تدخل من أول ما تفتح الراوتر لحد ما تبرمج منفذ، وترجع تاني لبره:

enable
configure terminal
interface g0/0
end

الإعداد خطوة بخطوة

enable User EXEC

Router> Exam PT ✔

الصيغة:

enable

الشرح: بينقلك من الـ User EXEC mode (اللي علامته >) للـ Privileged EXEC mode (اللي علامته #). الوضع ده بيديك صلاحيات تشوف كل الإعدادات (show) وتعمل حفظ.

مثال:

Router> enable
Router#

للتأكد: شكل الـ Prompt هيتغير لـ #.

disable Privileged EXEC

Router# Exam PT ✔

الصيغة:

disable

الشرح: بيعمل العكس، بينزلك من الـ Privileged EXEC mode لـ User EXEC mode.

مثال:

Router# disable
Router>

configure terminal Privileged EXEC

Router# Exam PT ✔

الصيغة:

configure terminal

الشرح: بيدخلك على الـ Global Configuration mode اللي تقدر منه تغير برمجة الراوتر ككل. علامته (config)#.

مثال:

Router# configure terminal
Router(config)#

انتبه: معظم المهندسين بيكتبوها باختصار conf t.

exit / end Any Mode

Router(config...)# Exam PT ✔

الصيغة:

exit
end

الشرح: أمر exit بيرجعك خطوة واحدة لورا في التسلسل الهرمي. أمر end (أو اختصار Ctrl+Z) بيرجعك فوراً للـ Privileged EXEC mode مهما كنت متعق في الإعدادات الفرعية.

مثال:

Router(config-if)# exit
Router(config)# end
Router#

do <command> Config modes

Router(config...)# Exam PT ✔

الصيغة:

do <command>

إيه اللي بنحطه مكان القيم:

  • <command> = أي أمر من أوامر Privileged EXEC زي show أو ping أو write.

الشرح: بيسمحلك تنفذ أوامر الفحص والـ show وإنت لسة جوة وضع الإعدادات، بدل ما تضطر تخرج بـ end وتنفذ الأمر وترجع تدخل تاني.

مثال:

Router(config-if)# do show ip interface brief

انتبه: لما بتستخدم do، زرار الـ Tab مش بيكمل الكلمة لوحده زي العادي.

? Any Mode

الصيغة:

?
<command> ?

الشرح: علامة الاستفهام بتعرضلك كل الأوامر المتاحة في الوضع الحالي. لو كتبتها بعد أمر معين، هتقولك إيه الخيارات المتاحة للأمر ده.

مثال:

Router# clock ?
  set  Set the time and date

| include / exclude / begin / section Privileged EXEC

Router# Exam PT Partial

الصيغة:

show <command> | { include | exclude | begin | section } <Regex>

إيه اللي بنحطه مكان القيم:

  • <command> = أي أمر زي show running-config.
  • <Regex> = الكلمة أو النص اللي بتدور عليه. حساس لحالة الأحرف (Capital/Small).

الشرح: بيعمل فلترة لنتائج أوامر الـ show الطويلة:

  • include: يعرض السطور اللي فيها الكلمة دي بس.
  • exclude: يعرض كل السطور ما عدا اللي فيها الكلمة دي.
  • begin: يعرض النتائج بدايةً من أول سطر يلاقي فيه الكلمة دي للآخر.
  • section: بيعرض الفقرة كاملة (الجزء اللي الكلمة دي جواه).

مثال:

Router# show running-config | include ip address
Router# show running-config | section ospf

انتبه: الـ Packet Tracer مش دايماً بيدعم section أو count.

terminal length 0 Privileged EXEC

Router# Extra PT ✔

الصيغة:

terminal length 0

الشرح: بيلغي التوقف عند كلمة --More-- وبيخلي مخرجات الأوامر الطويلة تطبع كلها دفعة واحدة في الشاشة. مفيد جداً لما تحب تنسخ إعدادات الراوتر كلها بدون ما تضغط المسطرة كل شوية.

مثال:

Router# terminal length 0
Router# show running-config

أوامر التحقق

1. show privilege

بيوريك مستوى الصلاحيات الحالي بتاعك.

Router# show privilege
Current privilege level is 15
  • Level 1: وضع المستخدم (User EXEC).
  • Level 15: وضع الامتيازات الكامل (Privileged EXEC).

فحص الأعطال ورسائل الخطأ

رسائل الأخطاء المشهورة في الـ CLI

Error Message السبب بالعربي
% Invalid input detected at '^' marker. الراوتر مش فاهم الكلمة اللي مكتوبة عند علامة ^. ممكن تكون كاتب حرف غلط أو الأمر مش مدعوم في الوضع الحالي.
% Incomplete command. الأمر صح، بس ناقصه متغيرات أو كلام تاني بعده عشان يكمل. استخدم ? عشان تعرف الناقص.
% Ambiguous command. أنت كتبت اختصار لأمر، بس الاختصار ده بيشترك فيه أكتر من أمر. لازم تزود حروف كمان. (مثلاً c بس ممكن تبقى configure أو copy).
Translating "..."...domain server (255.255.255.255) أنت كتبت كلمة غلط والراوتر افتكرها اسم جهاز وبيحاول يعملها DNS Lookup. الحل: اضغط Ctrl+Shift+6 عشان تلغي البحث بسرعة.

أخطاء شائعة وفخاخ الامتحان

  • تكتب show run وأنت لسة جوة الـ (config)# وتستغرب إنه مش شغال، الحل إنك تكتب قبله do.
  • الفرق بين no و default: عشان تلغي أي أمر استخدم قبله no. أمر default بيرجع الإعداد لقيمته الأصلية (مثال: default interface g0/0 بيمسح برمجة المنفذ كلها).
  • البحث بالـ Pipe (|) دايماً Case-Sensitive، لو كتبت include ospf مش هيلاقي كلمة OSPF بالحروف الكبيرة.

جدول مختصر (اختصارات لوحة المفاتيح)

Shortcut الوظيفة (Purpose)
Tab إكمال الكلمة تلقائياً لو كتبت جزء مميز منها.
Ctrl + A نقل المؤشر لأول السطر.
Ctrl + E نقل المؤشر لآخر السطر.
Ctrl + U مسح السطر بالكامل.
Ctrl + C / Ctrl + Z الخروج للـ Privileged EXEC.
Ctrl + Shift + 6 إلغاء عملية الـ Ping أو التتبع أو الـ DNS Lookup المزعج.
