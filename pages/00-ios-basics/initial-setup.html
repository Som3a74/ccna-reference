CCNA Reference

الإعداد المبدئي (Initial Setup)

نبذة سريعة

أول ما بتفتح راوتر أو سويتش جديد، فيه شوية أوامر أساسية بنعملها عشان نظبط اسم الجهاز، نمنعه من إنه يعلق بسبب أخطاء الكتابة، وننظم شكل الرسايل والوقت عليه عشان يسهل علينا إدارته بعدين.

إعداد سريع (انسخ والصق)

دي الأوامر المعتادة لأي جهاز جديد عشان تخليه جاهز ومريح في الشغل:

enable
configure terminal
hostname R1
no ip domain-lookup
service timestamps log datetime msec
line con 0
 logging synchronous
 exec-timeout 15 0
 exit
banner motd #
UNAUTHORIZED ACCESS IS PROHIBITED
#
end
clock set 14:00:00 25 Oct 2026

الإعداد خطوة بخطوة

hostname Global config

Router(config)# Exam PT ✔

الصيغة:

hostname <name>

إيه اللي بنحطه مكان القيم:

  • <name> = اسم الجهاز الجديد (بدون مسافات).

الشرح: بيغير اسم الراوتر أو السويتش، وده مهم جداً عشان متتلخبطش وإنت فاتح أكتر من شاشة.

مثال:

Router(config)# hostname R1
R1(config)#

no ip domain-lookup Global config

Router(config)# Exam PT ✔

الصيغة:

no ip domain-lookup

الشرح: بيلغي خاصية البحث عن العناوين عبر الـ DNS لو كتبت أمر غلط. من غيره، أي كلمة بتكتبها غلط الراوتر بيفتكرها اسم جهاز وبيحاول يتصل بيه وياخد 30 ثانية يعلق فيهم.

مثال:

R1(config)# no ip domain-lookup

banner motd Global config

Router(config)# Exam PT ✔

الصيغة:

banner { motd | login | exec } <delimiter>
  <text>
<delimiter>

إيه اللي بنحطه مكان القيم:

  • motd | login | exec = نوع الرسالة. (motd رسالة اليوم، login بتظهر قبل الباسوورد، exec بتظهر بعد الدخول).
  • <delimiter> = رمز بتستخدمه عشان تحدد بداية ونهاية الرسالة (زي # أو %).
  • <text> = محتوى الرسالة التحذيرية.

الشرح: بيطبع رسالة ترحيب أو تحذير لأي حد يحاول يدخل على الجهاز. ضرورية جداً قانونياً للشركات (مثال: الدخول مسموح للمصرح لهم فقط).

مثال:

R1(config)# banner motd #
Enter TEXT message.  End with the character '#'.
WARNING: Authorized Access Only!
#

clock set Privileged EXEC

Router# Exam PT ✔

الصيغة:

clock set <hh:mm:ss> <day> <month> <year>

إيه اللي بنحطه مكان القيم:

  • <hh:mm:ss> = الوقت الحالي بالساعات والدقايق والثواني (نظام 24 ساعة).
  • <day> <month> <year> = اليوم (رقم)، الشهر (كلمة إنجليزي، مثلاً Oct)، السنة (مثلاً 2026).

الشرح: بيضبط وقت وتاريخ الراوتر الداخلي. مهم جداً عشان سجلات الأحداث (Logs) والشهادات الأمنية.

مثال:

R1# clock set 14:30:00 25 Oct 2026

انتبه: الأمر ده بيتكتب في الـ Privileged EXEC (#) مش في الـ Config، وده استثناء من الأوامر اللي بتغير إعدادات الجهاز!

service timestamps Global config

Router(config)# Exam PT ✔

الصيغة:

service timestamps { log | debug } datetime msec

الشرح: بيخلي الراوتر يحط التاريخ والوقت (بالأجزاء من الثانية) على كل رسالة خطأ أو حدث (Log). لو معملتوش، الرسايل هتطبع بأرقام بتعبر عن الوقت اللي مر من ساعة ما الراوتر اشتغل (Uptime) وده مبيكونش مفيد في فحص الأعطال.

مثال:

R1(config)# service timestamps log datetime msec
R1(config)# service timestamps debug datetime msec

logging synchronous Line config

Router(config-line)# Exam PT ✔

الصيغة:

logging synchronous

الشرح: أهم أمر لراحتك كمهندس. بيمنع إن رسائل الـ Logs تقطع الكلام اللي إنت بتكتبه. لو مفيش الأمر ده، وإنت بتكتب أي سطر والراوتر طلّع رسالة عن منفذ وقع، الرسالة هتدخل وسط كلامك وتلخبط الشاشة.

مثال:

R1(config)# line con 0
R1(config-line)# logging synchronous

exec-timeout Line config

Router(config-line)# Exam PT ✔

الصيغة:

exec-timeout <minutes> <seconds>

إيه اللي بنحطه مكان القيم:

  • <minutes> = الدقايق.
  • <seconds> = الثواني.

الشرح: بيحدد امتى الراوتر يطردك من الجلسة (Session) لو مكتبتش أي حاجة (Idle timeout). الافتراضي بيكون 10 دقايق. لو كتبته 0 0 معناه مستحيل يطردك (تُستخدم في اللاب بس، وخطر جداً في الحقيقة).

مثال:

R1(config)# line con 0
R1(config-line)# exec-timeout 15 0

شرح المثال بالعربي: خلينا المهلة 15 دقيقة وصفر ثانية.

description Interface config

Router(config-if)# Exam PT ✔

الصيغة:

description <text>

إيه اللي بنحطه مكان القيم:

  • <text> = وصف للمنفذ بيشرح هو واصل بإيه.

الشرح: بيكتب ملاحظة على الـ Interface بتفضل موجودة في الإعدادات، مفيدة جداً وقت فحص الأعطال عشان تعرف الكابل ده رايح فين بدل ما تمشي وراه.

مثال:

R1(config)# interface g0/0
R1(config-if)# description Link to SW1-Core

للتأكد: show interfaces description

أوامر التحقق

1. show clock

بيوريك الوقت الحالي المتسجل على الجهاز.

R1# show clock
*14:35:12.125 UTC Sun Oct 25 2026

2. show interfaces description

بيعرض كل المنافذ والوصف المكتوب عليها وحالتها.

R1# show interfaces description
Interface                      Status         Protocol Description
Gi0/0                          up             up       Link to SW1-Core
Gi0/1                          admin down     down

مواقف متكررة وفحص الأعطال

  • ليه الراوتر بيعلق لما أغلط في كتابة أمر؟
    لأن أمر no ip domain-lookup مش مكتوب. الراوتر بيفترض إنك كتبت اسم دومين وبيحاول يكلم الـ DNS. عشان تلغي التعليقة دي فوراً، اضغط Ctrl + Shift + 6.
  • ليه وإنت بتكتب أمر تلاقي رسالة نطت بوظت السطر؟
    لأنك مكتبتش logging synchronous جوة إعدادات الكونسول أو الـ VTY.
  • الـ Banner مش راضي يقفل ويحفظ الكلام؟
    لأنك مأنهيتش الرسالة بنفس الرمز (delimiter) اللي بدأتها بيه (مثال: لازم تكتب # في آخر سطر لو بدأت بـ #).

أخطاء شائعة وفخاخ الامتحان

  • أمر clock set هو أمر Privileged EXEC مش أمر Global Config. متكتبوش جوة (config)# وإلا هتاخد Invalid input.
  • أمر exec-timeout 0 0 بيتلغي بيه وقت الطرد، ده غلط كبير تعمله في شبكة حقيقية لأن لو قمت من على الكرسي أي حد يقدر يفتح الشاشة بعدك، ده بس عشان راحتك وإنت بتذاكر في اللاب.

جدول مختصر

Command الوظيفة (Purpose)
hostname <name> تغيير اسم الجهاز.
no ip domain-lookup منع البحث في الـ DNS عند كتابة أمر خاطئ.
banner motd # وضع رسالة تحذيرية قبل الدخول.
clock set hh:mm:ss dd MMM YYYY ضبط ساعة الجهاز يدوياً.
service timestamps log datetime msec وضع وقت دقيق جداً على كل حدث أو Log.
logging synchronous منع تداخل رسائل الجهاز مع كتابتك.
exec-timeout <min> <sec> التحكم في وقت فصل الجلسة عند الخمول.
description <text> كتابة وصف لأي منفذ (Interface).
