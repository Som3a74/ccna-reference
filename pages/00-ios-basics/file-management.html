إدارة الملفات وحفظ الإعدادات (File Management)

نبذة سريعة

أجهزة سيسكو بتعتمد على 4 أنواع أساسية من الذاكرة:

  • RAM: الذاكرة العشوائية السريعة، وعليها الإعدادات الحالية (running-config). بتتمسح لو الكهربا قطعت.
  • NVRAM: الذاكرة الدايمة، وعليها الإعدادات المحفوظة (startup-config).
  • Flash: زي الهارد ديسك، وعليها نظام التشغيل (IOS) وملف الـ VLANs.
  • ROM: عليها نظام بدائي (ROMMON) بيشتغل لو نظام التشغيل الأساسي وقع أو عشان تكسر الباسوورد.

إعداد سريع (انسخ والصق)

عشان تحفظ شغلك فوراً عشان ميضيعش لو الجهاز عمل ريستارت:

copy running-config startup-config

الإعداد خطوة بخطوة

show running-config / startup-config Privileged EXEC

Router# Exam PT ✔

الصيغة:

show running-config
show startup-config

الشرح: أمر show running-config بيعرضلك كل الإعدادات اللي شغالة حالياً في الـ RAM. أما أمر show startup-config بيعرض الإعدادات المحفوظة في الـ NVRAM واللي هتشتغل لو الجهاز عمل ريستارت.

مثال:

Router# show running-config

copy running-config startup-config Privileged EXEC

Router# Exam PT ✔

الصيغة:

copy running-config startup-config

الشرح: أهم أمر في سيسكو. بياخد نسخة من الشغل الحالي بتاعك ويحفظه في الذاكرة الدايمة. لو معملتوش وعملت ريستارت، كل شغلك هيضيع.

مثال:

Router# copy running-config startup-config
Destination filename [startup-config]? 
Building configuration...
[OK]

انتبه: مهندسين كتير بيستخدموا أمر write memory (أو اختصار wr) كبديل أسرع، وهو شغال ومقبول جداً في الواقع والامتحان، بس copy هو الأمر الرسمي الأحدث.

copy ... tftp: Privileged EXEC

Router# Exam PT ✔

الصيغة:

copy { running-config | startup-config | flash:<filename> } tftp:

الشرح: بيعمل نسخة احتياطية من الإعدادات أو من نظام التشغيل (IOS) ويبعتها لسيرفر خارجي (TFTP). هيسألك على الـ IP بتاع السيرفر واسم الملف اللي عايز تحفظه بيه.

مثال:

Router# copy running-config tftp:
Address or name of remote host []? 192.168.1.100
Destination filename [router-confg]? R1-Backup-Oct2026.cfg
!!
[OK - 1500 bytes]

erase startup-config Privileged EXEC

Router# Exam PT ✔

الصيغة:

erase startup-config

الشرح: بيمسح كل الإعدادات المحفوظة في الـ NVRAM عشان يرجع الجهاز لإعدادات المصنع (لازم تعمله reload بعدها عشان التغيير يطبق وتفضي الـ RAM).

مثال:

Router# erase startup-config
Erasing the nvram filesystem will remove all configuration files! Continue? [confirm]
[OK]
Erase of nvram: complete

انتبه: في السويتشات، مسح الـ startup-config مش بيمسح الـ VLANs. عشان تمسح الـ VLANs وتعمل ضبط مصنع كامل، لازم تكتب كمان delete flash:vlan.dat.

reload Privileged EXEC

Router# Exam PT ✔

الصيغة:

reload [ in <minutes> | at <hh:mm> ]

إيه اللي بنحطه مكان القيم:

  • in <minutes> = (اختياري) يعمل ريستارت بعد عدد معين من الدقايق.
  • at <hh:mm> = (اختياري) يعمل ريستارت في وقت محدد.

الشرح: بيعمل ريستارت (Reboot) للجهاز. لو مجرد كتبت reload هيعمل ريستارت فوراً. خاصية الوقت (reload in) مفيدة جداً لو بتجرب أمر خايف يقطع الاتصال عنك وإنت بعيد، لو الاتصال قطع الجهاز هيعمل ريستارت بعد الوقت ده ويرجع للإعدادات القديمة، ولو الأمر طلع سليم تقدر تلغي الريستارت بـ reload cancel.

مثال:

Router# reload in 5
Reload scheduled in 5 minutes by console.

show flash / dir Privileged EXEC

Router# Exam PT ✔

الصيغة:

show flash:
dir flash:

الشرح: بيعرض الملفات اللي موجودة في ذاكرة الـ Flash، وأهمها ملف نظام التشغيل (اللي آخره .bin) وملف vlan.dat في السويتشات.

مثال:

Router# dir flash:
Directory of flash:/
    1  -rw-    33591768  Oct 25 2026 14:15:02 +00:00  c2960-lanbasek9-mz.150-2.SE4.bin
    2  -rw-         616  Oct 25 2026 14:20:11 +00:00  vlan.dat

boot system Global config

Router(config)# Exam PT ✔

الصيغة:

boot system flash:<filename.bin>

إيه اللي بنحطه مكان القيم:

  • <filename.bin> = اسم ملف نظام التشغيل الجديد بالظبط زي ما طلع في show flash.

الشرح: بيعرّف الراوتر إنه لما يعمل ريستارت، يشغل النسخة دي من نظام التشغيل بدل النسخة القديمة.

مثال:

Router(config)# boot system flash:c2900-universalk9-mz.SPA.155-3.M4a.bin

للتأكد: show boot

config-register Global config

Router(config)# Exam PT Partial

الصيغة:

config-register <value>

إيه اللي بنحطه مكان القيم:

  • <value> = قيمة الهيكسا، أشهر اتنين هما 0x2102 (الطبيعي) و 0x2142 (تجاهل الـ startup-config لكسر الباسوورد).

الشرح: بيغير إعدادات البوت بتاعة الراوتر. القيمة 0x2102 معناها حمل الـ IOS وبعدين حمل الـ startup-config. القيمة 0x2142 معناها حمل الـ IOS وتجاهل الـ startup-config كأن الراوتر جديد تماماً، ودي الخطوة الأساسية في كسر الباسوورد.

مثال:

Router(config)# config-register 0x2102

archive & configure replace Global config

Router(config)# Extra PT ✖

الصيغة:

archive
 path flash:<directory>/<prefix>
 write-memory

الشرح: بيخلي الراوتر ياخد نسخة احتياطية من الإعدادات أوتوماتيكياً في ملف جوة الـ Flash كل ما تعمل write memory. عشان ترجع للنسخة دي في أي وقت، بتستخدم الأمر الرهيب configure replace flash:<filename> اللي بيمسح التغييرات اللي عملتها ويرجعك للحالة اللي متسجلة في الملف من غير ريستارت.

مثال:

Router(config)# archive
Router(config-archive)# path flash:mybackup-
Router(config-archive)# write-memory

أوامر التحقق

1. show version

أمر شامل بيعرض نسخة نظام التشغيل، وقت التشغيل (Uptime)، مكونات الجهاز (الرامات والـ Flash)، وأهم حاجة في الآخر بيعرض قيمة الـ Configuration register.

Router# show version
Cisco IOS Software, C2900 Software (C2900-UNIVERSALK9-M), Version 15.5(3)M4a
...
255K bytes of non-volatile configuration memory.
255488K bytes of ATA System CompactFlash (Read/Write)

Configuration register is 0x2102

خطوات ترقية نظام التشغيل (IOS Upgrade)

عشان تحدث نظام الجهاز، بتتبع الخطوات دي (نظرياً في الامتحان):

  1. اتأكد إن الـ Flash فيه مساحة فاضية باستخدام show flash.
  2. انقل الملف الجديد للراوتر باستخدام copy tftp: flash:.
  3. عرّف الراوتر إنه يبوت من الملف الجديد باستخدام boot system flash:<filename.bin>.
  4. احفظ الإعدادات copy run start.
  5. اعمل ريستارت reload واتأكد إن النسخة الجديدة اشتغلت باستخدام show version.

خطوات كسر الباسوورد (Password Recovery)

لو نسيت باسوورد الدخول على الراوتر:

  1. اقفل الراوتر وافتحه (Power Cycle).
  2. في أول ثواني، اضغط Ctrl + Pause/Break (أو من الـ Terminal الخاصية المقابلة) عشان توقف البوت وتدخل على وضع ROMMON (شاشته بتبقى rommon 1 >).
  3. غير الـ Register عشان يتجاهل ملف الإعدادات المحفوظة: اكتب confreg 0x2142 وبعدها reset.
  4. الراوتر هيفتح كأنه جديد من غير باسووردات. ادخل وضع الامتيازات واكتب copy startup-config running-config عشان ترجع كل إعداداتك القديمة للـ RAM (من غير ما الباسوورد تمنعك لأنك دخلت خلاص).
  5. غير الباسوورد القديمة بأمر enable secret جديد.
  6. غير الـ Register للوضع الطبيعي تاني config-register 0x2102 (من وضع الإعدادات Global config).
  7. احفظ شغلك copy run start.

أخطاء شائعة وفخاخ الامتحان

  • أمر copy startup-config running-config مش بيمسح اللي موجود في الـ RAM وبيحط الـ NVRAM مكانه، ده بيعمل دمج (Merge) بينهم. يعني لو إنت كاتب أمر في الـ RAM ومش موجود في الـ NVRAM، هيفضل موجود مش هيتمسح. لو عايز تمسح كل حاجة وترجع للـ startup، لازم تعمل reload (أو تستخدم configure replace لو مفعّلها).
  • مسح الـ VLANs في السويتش مش بيتم بـ erase startup-config. لازم تمسح ملف الـ VLAN من الفلاش منفصلاً delete flash:vlan.dat.

جدول مختصر

Command الوظيفة (Purpose)
copy run start حفظ الإعدادات من الـ RAM للـ NVRAM.
write memory (wr) نفس وظيفة copy run start (الأمر الأقدم).
erase startup-config مسح الإعدادات المحفوظة للعودة لضبط المصنع.
reload إعادة تشغيل الجهاز.
show version عرض مواصفات الجهاز ونسخة الـ IOS والـ Register.
show flash عرض ملفات نظام التشغيل والمساحة المتاحة.
config-register 0x2142 تجاوز الـ startup-config لكسر الباسوورد.
