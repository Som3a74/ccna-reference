CCNA Reference

الشبكات اللاسلكية (Wireless LAN & WLC)

نبذة سريعة

في منهج CCNA الحديث، إعدادات الشبكات اللاسلكية مش بتتم بأوامر الشاشة السوداء (CLI) زي الروترات، لكن بتتم من خلال واجهة المستخدم الرسومية (GUI) لجهاز الـ WLC (Wireless LAN Controller). الـ WLC هو العقل المدبر اللي بيتحكم في كل أجهزة الـ Access Points (APs) اللي في المبنى. بروتوكول CAPWAP هو اللي بيربط الـ AP بالـ WLC.

إعداد سريع (إعدادات السويتش)

عشان تركب WLC و AP في الشبكة بتاعتك، دي إعدادات السويتش اللي هتوصلهم عليه:

! البورت الواصل بالـ WLC (لازم يكون Trunk)
interface g0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20,99

! البورت الواصل بالـ AP العادي (لازم يكون Access)
interface g0/2
 switchport mode access
 switchport access vlan 99
 ! الـ AP بيحتاج كهرباء عبر الكابل
 power inline auto

مفاهيم الـ WLC GUI (للامتحان)

1. إنشاء شبكة وايرلس جديدة (WLAN)

WLC GUI Exam

الخطوات:

  1. بتدخل على قائمة WLANs من القائمة العلوية.
  2. بتختار Create New وتضغط Go.
  3. بتكتب اسم الشبكة (Profile Name) واسم الـ SSID اللي هيظهر للموبايلات واللابات.
  4. بتختار رقم الـ WLAN ID (يفضل يكون نفس رقم الـ VLAN عشان متتلخبطش).

2. إعدادات الحماية (Security)

WLC GUI Exam

الخطوات:

  • من داخل إعدادات الـ WLAN، بتروح لتاب Security وبعدين Layer 2.
  • لعمل باسورد عادية (زي البيت): بتختار WPA+WPA2، وتعلم على PSK وتكتب الباسورد.
  • لربط الشبكة بسيرفر حسابات للموظفين: بتختار 802.1x.

معلومة للامتحان: بروتوكول WPA2 بيستخدم تشفير AES/CCMP وهو الآمن، بينما WPA القديم بيستخدم TKIP.

3. ربط الـ WLAN بالـ VLAN

WLC GUI Exam

الشرح:

من تاب General جوه إعدادات الـ WLAN، بتلاقي اختيار اسمه Interface/Interface Group. هنا بتختار الـ Dynamic Interface (اللي بيمثل الـ VLAN) اللي عايز الناس اللي تدخل على الوايرلس ده تسحب IP منها.

5. الإدارة السحابية للأجهزة (Cisco Meraki)

Exam Core Cloud Architecture

معمارية Cisco Meraki للامتحان:

  • Out-of-band Cloud Management: لوحة تحكم سحابية مركزية (Meraki Dashboard). بيانات المستخدمين (Data Plane) تمر محلياً عبر الأجهزة ولا تصعد للسحابة إطلاقاً. فقط بيانات المراقبة والكونفيج (Management Plane) هي التي تمر إلى سيرفرات سيسكو عبر أنفاق HTTPS/TLS آمنة.
  • Zero-Touch Provisioning: بمجرد توصيل جهاز Meraki الجديد (MR Access Point أو MS Switch أو MX Security Appliance) بالكهرباء والإنترنت، يسحب عنوان IP عبر DHCP ويتصل بالسحابة تلقائياً ويحمل إعداداته خلال دقائق.

فحص الأعطال (Troubleshooting)

الـ AP مش قادر يوصل للـ WLC

لو الـ AP مش راضي ينور أخضر ومش ظاهر في الـ WLC، اتاكد من الحاجات دي:

  • DHCP: الـ AP أول ما بيشتغل بيحتاج يسحب IP عشان يقدر يكلم الـ WLC، لو مفيش DHCP سيرفر شغال، الـ AP هيعطل.
  • Option 43: ده أوبشن بيتحط في الـ DHCP عشان يقول للـ AP "عنوان الـ WLC بتاعك هو كذا". بدونه، الـ AP هيعمل Broadcast وممكن ميوصلش للـ WLC لو هما في VLANs مختلفة.

أخطاء شائعة وفخاخ الامتحان

  • Access vs Trunk: البورت الواصل بالـ WLC دائماً Trunk (عشان بيشيل الداتا بتاعة كل شبكات الوايرلس). البورت الواصل بالـ AP في وضع الـ Local Mode دائماً Access (لأن الـ AP بيبعت الداتا متغلفة في نفق CAPWAP).
  • Local vs FlexConnect: في وضع الـ Local، الداتا بتروح للـ WLC الأول. في وضع الـ FlexConnect، الـ AP بيقدر يطلع الداتا على السويتش مباشرة (وساعتها بورت الـ AP لازم يكون Trunk).
  • WLC Management: عشان تدخل على الـ WLC وتعمل إعداداته، لازم تستخدم HTTPS من المتصفح للـ IP الخاص بالـ Management Interface.

جدول مختصر لمصطلحات الوايرلس

Term المعنى
WLC العقل المدبر اللي بيتحكم في كل أجهزة الوايرلس (Controller).
CAPWAP النفق اللي بيتبني بين الـ AP والـ WLC لنقل الإعدادات والداتا.
WLAN اسم شبكة الوايرلس اللي بتكريتها (موازية للـ VLAN في السلكي).
SSID اسم الشبكة اللي بيظهر للناس على موبايلاتهم.
PSK Pre-Shared Key، يعني الباسورد العادية بتاعة الوايرلس.
802.1x حماية متقدمة، كل يوزر ليه Username و Password خاصين بيه.
