CCNA Reference

بروتوكول الشجرة الممتدة (Spanning Tree Protocol)

نبذة سريعة

بروتوكول STP وظيفته الأساسية هي منع حدوث اللوب (Loops) في الشبكة عن طريق قفل مسارات احتياطية وتشغيلها بس لو المسار الأساسي وقع. في منهج CCNA، التركيز الأكبر بيكون على نسخة Rapid PVST+ السريعة اللي بتعمل شجرة لكل VLAN لوحدها.

إعداد سريع (انسخ والصق)

لتحويل السويتش لنسخة الـ Rapid، وجعله هو القائد (Root) للـ VLAN 10، مع تفعيل الحماية على منفذ الكمبيوتر:

spanning-tree mode rapid-pvst
spanning-tree vlan 10 root primary

interface g0/1
 spanning-tree portfast
 spanning-tree bpduguard enable

الإعداد خطوة بخطوة

spanning-tree mode Global config

Switch(config)# Exam PT ✔

الصيغة:

spanning-tree mode { pvst | rapid-pvst }

الشرح: بيغير نسخة الـ STP اللي شغالة. pvst هي النسخة القديمة البطيئة (بتاخد 50 ثانية عشان تفتح البورت)، بينما rapid-pvst هي النسخة السريعة (بتفتح في أقل من ثانيتين).

root primary / secondary Global config

Switch(config)# Exam PT ✔

الصيغة:

spanning-tree vlan <vlan-id> root { primary | secondary }

الشرح: السويتش اللي بيبقى Root Bridge هو المركز اللي كل الداتا بتمشي من خلاله. أمر primary بيقلل الـ Priority بتاعة السويتش عشان تضمن إنه يكسب الانتخابات ويبقى هو القائد. أمر secondary بيخليه القائد الاحتياطي لو الأولاني وقع.

spanning-tree priority Global config

Switch(config)# Exam PT ✔

الصيغة:

spanning-tree vlan <vlan-id> priority <value>

الشرح: طريقة تانية يدوية عشان تتحكم في السويتش اللي هيكسب الانتخابات. السويتش صاحب أقل رقم بيكسب (الافتراضي 32768). لازم الرقم اللي تكتبه هنا يكون من مضاعفات الـ 4096 (مثلاً: 0، 4096، 8192، إلخ).

portfast Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

spanning-tree portfast

الشرح: بيخلي البورت يفتح فوراً بمجرد ما الكابل يركب (بيلغي الـ 50 ثانية تأخير). تحذير خطير: الأمر ده ميتعملش غير على البورتات اللي واصلة بأجهزة نهائية (كمبيوتر، طابعة، سيرفر). لو عملته على بورت واصل بسويتش تاني هيعمل Loop فوري يوقع الشبكة.

bpduguard Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

spanning-tree bpduguard enable

الشرح: إضافة أمنية قوية. البورت اللي متفعل عليه الأمر ده، لو بالغلط حد وصل فيه سويتش بدل كمبيوتر (والسويتش بيبعت رسائل BPDU بتاعت الـ STP)، البورت هيقفل نفسه فوراً ويدخل في حالة Error-Disable عشان يحمي الشبكة.

أوامر التحقق

1. show spanning-tree

الأمر الأهم على الإطلاق لمراقبة الشجرة ومعرفة مين القائد ومين البورت المقفول.

SW1# show spanning-tree vlan 10

             This bridge is the root
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec

             Address     0011.2233.4455
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec

Interface           Role Sts Cost      Prio.Nbr Type
------------------- ---- --- --------- -------- --------------------------------
Fa0/1               Desg FWD 19        128.1    P2p
Fa0/2               Desg FWD 19        128.2    P2p

إزاي تقرا الجدول:

  • Root ID: دي بيانات السويتش القائد في الشبكة.
  • Bridge ID: دي بيانات السويتش بتاعك إنت اللي واقف عليه.
  • جملة This bridge is the root: معناها إن السويتش اللي إنت فاتحه دلوقتي هو نفسه السويتش القائد. دي بتيجي سؤال مؤكد في الامتحان.
  • Role / Sts: البورتات الـ FWD معناها مفتوحة وبتنقل داتا. لو لقيت بورت مكتوب قصاده BLK أو Altn ده معناه إنه البورت المقفول (Blocked) عشان يمنع اللوب.

فحص الأعطال (Troubleshooting)

بورت الكمبيوتر مقفول (ErrDisable)

لو بورت كان شغال وفجأة قفل ولقيت رسالة: %SPANTREE-2-BLOCK_BPDUGUARD: Received BPDU on port Fa0/1 with BPDU Guard enabled. Disabling port.، ده معناه إن فيه مستخدم جاب سويتش صغير من البيت ووصله في بورت المكتب. الـ BPDUGuard اصطاد رسالة السويتش وقفل البورت لحماية الشبكة. عشان ترجعه، لازم تشيل السويتش الغريب وتعمل للبورت shutdown وبعدين no shutdown.

أخطاء شائعة وفخاخ الامتحان

  • أقل MAC بيكسب: لو كل السويتشات ليها نفس الـ Priority (وهو ده الافتراضي)، السويتش اللي الـ MAC Address بتاعه أقل هو اللي بيبقى القائد. الامتحان بيجيبلك 3 سويتشات ويقولك مين فيهم القائد.
  • مضاعفات الـ 4096: متقدرش تكتب priority 1000 مثلاً. لازم الرقم يكون من مضاعفات الـ 4096.
  • PortFast مع الـ Trunk: أوعى تفعل PortFast على Trunk. هينتج عنه لوب لحظي لحد ما البورتات التانية تكتشفه.

جدول مختصر

Command الوظيفة (Purpose)
spanning-tree mode rapid-pvst تغيير نسخة الـ STP للنسخة السريعة.
spanning-tree vlan <id> root primary جعل هذا السويتش هو القائد للشبكة.
spanning-tree vlan <id> priority <num> تغيير الأولوية يدوياً (مضاعفات 4096).
spanning-tree portfast جعل المنفذ يفتح فوراً (لأجهزة المستخدمين فقط).
spanning-tree bpduguard enable إغلاق المنفذ فوراً إذا تم توصيل سويتش غريب به.
show spanning-tree عرض حالة الشجرة، القائد، وحالة المنافذ.
