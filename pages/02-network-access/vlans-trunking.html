شبكات VLAN ومسارات الـ Trunking

نبذة سريعة

تقنية الـ VLAN بتسمحلك تقسم السويتش الواحد كأنه أكتر من سويتش منفصلين، عشان تعزل الأقسام عن بعضها وتقلل الزحمة (Broadcast). الـ Trunk هو الكابل اللي بيربط بين السويتشات وبيقدر يشيل كل الـ VLANs مع بعض باستخدام تاج (Tag) بروتوكول 802.1Q.

إعداد سريع (انسخ والصق)

1. إنشاء VLAN وتخصيص منفذ أجهزة (Access Port)

vlan 10
 name IT-Dept
 exit
interface g0/1
 switchport mode access
 switchport access vlan 10
 no shutdown

2. إعداد منفذ ربط بين السويتشات (Trunk Port)

interface g0/2
 switchport mode trunk
 switchport nonegotiate
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 no shutdown

الإعداد خطوة بخطوة

vlan / name Global config

Switch(config)# Exam PT ✔

الصيغة:

vlan <vlan-id>
 name <vlan-name>

الشرح: بينشئ شبكة تخيلية جديدة ويديها اسم (عشان التنظيم). الأرقام المتاحة للاستخدام العادي من 2 لـ 1001.

switchport mode access Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

switchport mode access
switchport access vlan <vlan-id>
switchport voice vlan <vlan-id>

الشرح: بيجبر المنفذ إنه يتوصل بجهاز نهائي (زي كمبيوتر أو طابعة) وميتفاوضش لعمل Trunk. أمر الـ voice بيستخدم لو موصل تليفون سيسكو (IP Phone)، وده بيخلي المنفذ يشيل VLAN الداتا للكمبيوتر و VLAN للصوت في نفس الوقت.

مثال:

SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10
SW1(config-if)# switchport voice vlan 50

switchport mode trunk Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

switchport trunk encapsulation dot1q
switchport mode trunk
switchport nonegotiate

الشرح: بيجبر المنفذ إنه يشتغل كـ Trunk ويشيل كل الشبكات. في السويتشات القديمة (زي 3560) لازم تكتب أمر الـ encapsulation dot1q الأول لأنها بتدعم بروتوكول ISL القديم، لكن السويتشات الحديثة مبتدعمش غير dot1q فمش بتحتاج الأمر ده. أمر nonegotiate بيقفل رسائل الـ DTP عشان الحماية.

trunk allowed / native Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

switchport trunk allowed vlan { <list> | all | none | add <list> | remove <list> }
switchport trunk native vlan <vlan-id>

الشرح: أمر allowed بيحدد إيه هي الـ VLANs المسموح تعدي في الكابل ده لزيادة الأمان. أمر native بيغير شبكة الـ Native (الافتراضية VLAN 1) لشبكة تانية للحماية من هجمات الـ VLAN Hopping، والداتا بتاعت الـ Native بتتبعت من غير Tag.

تحذير خطير: لو الكابل عليه VLAN 10 و 20، وعايز تضيف VLAN 30، إياك تكتب switchport trunk allowed vlan 30 بس! ده هيمسح 10 و 20 ويوقع الشبكة. لازم تستخدم كلمة add 30.

DTP (Dynamic Trunking) Interface config

Switch(config-if)# Exam PT ✔

الصيغة:

switchport mode dynamic { auto | desirable }

الشرح: بروتوكول DTP بيتفاوض أوتوماتيك عشان يحول الكابل لـ Trunk.

  • desirable: السويتش هو اللي بيبدأ يطلب من الطرف التاني إنه يقلب Trunk.
  • auto: السويتش سلبي، بيستنى الطرف التاني يطلب الأول. لو الطرفين auto، المنفذ هيفضل Access ومش هيبقى Trunk أبدًا (فخ امتحان مشهور).

Router on a Stick (Inter-VLAN) Router config

Router(config)# Exam PT ✔

الصيغة:

interface <type><number>.<sub-id>
 encapsulation dot1Q <vlan-id> [native]
 ip address <ip-address> <subnet-mask>

الشرح: عشان الـ VLANs تكلم بعضها محتاجين راوتر. بنوصل السويتش (بمنفذ Trunk) براوتر، وفي الراوتر بنقسم المنفذ الفيزيائي لمنافذ وهمية (Sub-interfaces) كل واحد بيمثل Default Gateway لـ VLAN.

مثال:

R1(config)# interface g0/0
R1(config-if)# no shutdown   !--- لازم تفتح المنفذ الفيزيائي الأول
R1(config-if)# interface g0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0

أوامر التحقق

1. show vlan brief

أهم أمر عشان تتأكد إن الـ VLAN اتكريتت وإيه المنافذ (Access) اللي منتمية ليها. الأمر ده مش بيعرض منافذ الـ Trunk، منافذ الـ Trunk بتختفي من الجدول ده تماماً!

SW1# show vlan brief
VLAN Name                             Status    Ports
---- -------------------------------- --------- -------------------------------
1    default                          active    Fa0/2, Fa0/3, Fa0/4...
10   IT-Dept                          active    Fa0/1
20   HR-Dept                          active

2. show interfaces trunk

بيعرض كل منافذ الـ Trunk اللي على السويتش والـ VLANs المسموح ليها تعدي.

SW1# show interfaces trunk
Port        Mode             Encapsulation  Status        Native vlan
Gig0/1      on               802.1q         trunking      99

Port        Vlans allowed on trunk
Gig0/1      10,20,99

3. show interfaces <int> switchport

أمر قوي بيجيب كل تفاصيل منفذ معين، شغال Access ولا Trunk؟ والـ Native بتاعته كام؟ والـ DTP مقفول ولا لأ.

SW1# show interfaces g0/1 switchport
Name: Gig0/1
Switchport: Enabled
Administrative Mode: trunk
Operational Mode: trunk
Administrative Trunking Encapsulation: dot1q
Negotiation of Trunking: Off
Access Mode VLAN: 1 (default)
Trunking Native Mode VLAN: 99 (Management)

فحص الأعطال (Troubleshooting)

مشكلة Native VLAN Mismatch

لو غيرت الـ Native VLAN لـ 99 على سويتش ونسيت تغيرها على السويتش اللي قدامه، بروتوكول الـ CDP هيطلّع رسالة خطأ مزعجة بتظهر كل دقيقة على الشاشة: %CDP-4-NATIVE_VLAN_MISMATCH: Native VLAN mismatch discovered on GigabitEthernet0/1 (99), with SW2 GigabitEthernet0/1 (1). الحل إنك توحدهم.

الـ Router on a Stick مش شغال

أتأكد إنك عملت no shutdown للمنفذ المادي (Physical Interface) بتاع الراوتر زي g0/0 مش بس الـ Sub-interface، لأن الـ Sub-interface بيفضل مقفول طول ما المنفذ المادي مقفول.

أخطاء شائعة وفخاخ الامتحان

  • أمر الـ Add: افتكر دايماً فخ switchport trunk allowed vlan ADD. من غير كلمة add هتمسح كل اللي كان مسموح بيه.
  • اختفاء الـ Trunk: منافذ الـ Trunk مش بتظهر في أمر show vlan brief، لو ملقتش المنفذ، غالباً هو شغال Trunk.
  • تلقائية الـ VLAN: لو كتبت switchport access vlan 10 والشبكة دي مكنتش موجودة أصلاً، السويتش هيكريتها لوحده ويقولك Access VLAN does not exist. Creating vlan 10 (بس الأفضل دايماً تنشئها وتسميها بإيدك).

جدول مختصر

Command الوظيفة (Purpose)
switchport mode access إجبار المنفذ للعمل للاتصال بجهاز عادي (كمبيوتر).
switchport mode trunk إجبار المنفذ للعمل كوصلة بين السويتشات.
switchport mode dynamic desirable المنفذ يحاول بفاعلية أن يصبح Trunk.
switchport mode dynamic auto المنفذ ينتظر الطرف الآخر ليصبح Trunk (افتراضي لبعض الأجهزة).
switchport nonegotiate إيقاف رسائل التفاوض DTP (يُستخدم مع mode trunk/access الثابت).
show vlan brief عرض شبكات الـ VLAN والمنافذ الـ Access التابعة لها.
show interfaces trunk عرض منافذ الـ Trunk والـ Native VLAN الخاصة بكل منها.
