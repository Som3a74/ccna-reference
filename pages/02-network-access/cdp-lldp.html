بروتوكولات استكشاف الأجهزة المجاورة (CDP & LLDP)

نبذة سريعة

بروتوكولات الـ Discovery بتشتغل في الطبقة التانية (Layer 2) وبتسمح للأجهزة إنها تتعرف على الأجهزة المتوصلة بيها مباشرة (الـ Neighbors). بروتوكول CDP (Cisco Discovery Protocol) خاص بسيسكو وشغال افتراضياً، أما LLDP (Link Layer Discovery Protocol) فهو معيار عالمي بيشتغل على كل الأجهزة بس مقفول افتراضياً على سيسكو.

إعداد سريع (انسخ والصق)

لو عايز تشغل LLDP في الشبكة كلها، وتقفل الـ CDP على البورت اللي واصل بالإنترنت (للحماية):

lldp run
interface g0/0
 no cdp enable
 no lldp transmit

الإعداد خطوة بخطوة

cdp run Global config

Router(config)# Exam PT ✔

الصيغة:

cdp run
no cdp run

الشرح: أمر cdp run بيشغل البروتوكول على الجهاز كله. هو بيكون شغال بشكل افتراضي على أجهزة سيسكو. أمر no cdp run بيوقفه تماماً.

cdp enable Interface config

Router(config-if)# Exam PT ✔

الصيغة:

cdp enable
no cdp enable

الشرح: بيتحكم في تشغيل الـ CDP على بورت معين. من قواعد الحماية إنك تعمل no cdp enable على أي بورت واصل بجهاز مستخدم (PC) أو واصل بالإنترنت (ISP) عشان متكشفش تفاصيل شبكتك للمتطفلين.

lldp run Global config

Router(config)# Exam PT ✔

الصيغة:

lldp run
no lldp run

الشرح: بيشغل بروتوكول الـ LLDP على مستوى الجهاز. في أجهزة سيسكو، البروتوكول ده بيكون مقفول افتراضياً ولازم تشغله بالأمر ده لو عندك أجهزة في الشبكة مش من سيسكو (زي HP أو Juniper).

lldp transmit / receive Interface config

Router(config-if)# Exam PT ✔

الصيغة:

lldp transmit
lldp receive
no lldp transmit
no lldp receive

الشرح: على عكس الـ CDP اللي ليه أمر واحد للبورت، الـ LLDP بيديك تحكم أكبر؛ تقدر تخلي البورت يبعت رسايل بس، أو يستقبل بس، أو الاتنين.

أوامر التحقق

1. show cdp neighbors

من أشهر وأهم أوامر سيسكو على الإطلاق. بيوريك الأجهزة اللي واصلة بيك مباشرة (سيسكو بس). ونفس الفكرة لأمر show lldp neighbors.

R1# show cdp neighbors
Capability Codes: R - Router, T - Trans Bridge, B - Source Route Bridge
                  S - Switch, H - Host, I - IGMP, r - Repeater, P - Phone

Device ID        Local Intrfce     Holdtme    Capability  Platform  Port ID
SW1              Gig 0/0           120             S I    WS-C2960  Gig 0/1
R2               Gig 0/1           150           R        C1900     Gig 0/0

إزاي تقرا الجدول ده (مهم جداً للامتحان):

  • Device ID: اسم الجهاز اللي قدامك (الجار).
  • Local Intrfce: البورت بتاعك إنت اللي واصل بيه الكابل (عندي أنا).
  • Port ID: البورت بتاع الجار اللي الكابل داخل فيه (عنده هو).
  • في المثال اللي فوق: البورت Gig 0/0 بتاعي أنا واصل بالبورت Gig 0/1 بتاع السويتش SW1.

2. show cdp neighbors detail

بيجيب تفاصيل خطيرة عن الجار، أهمها الـ IP Address بتاعه (لأن الأمر العادي مبيظهرش الـ IP)، ونسخة الـ IOS اللي شغالة عليه.

فحص الأعطال (Troubleshooting)

جهاز جار مش ظاهر

لو جهاز واصل بيك ومش ظاهر في الـ show cdp neighbors، الأسباب ممكن تكون:

  • الجهاز التاني مش سيسكو (ساعتها لازم تستخدم LLDP).
  • الـ CDP مقفول على البورت (معمول له no cdp enable) أو مقفول على الجهاز كله.
  • البورت المادي نفسه مقفول (down/down). بروتوكولات الاكتشاف محتاجة Layer 2 شغال عشان تبعت رسايلها.

أخطاء شائعة وفخاخ الامتحان

  • run مقابل enable: افتكر دايماً إن cdp run بيشتغل في الـ Global، لكن cdp enable بيشتغل جوه الـ Interface. دي من أشهر لخبطات الامتحان.
  • الافتراضي: الـ CDP شغال افتراضياً، الـ LLDP مقفول افتراضياً.
  • Local vs Port ID: في أمر الجيران، Local Int هو بورتك إنت، و Port ID هو بورت الجار. الامتحان بيجيبلك صورة للجدول ويسألك ترسم الكابل واصل منين لفين.

جدول مختصر

Command البروتوكول الوظيفة (Purpose)
cdp run / no cdp run CDP (Global) تشغيل أو إيقاف CDP على الجهاز بالكامل.
cdp enable / no cdp enable CDP (Interface) تشغيل أو إيقاف CDP على منفذ محدد.
lldp run / no lldp run LLDP (Global) تشغيل أو إيقاف LLDP على الجهاز بالكامل.
lldp transmit / receive LLDP (Interface) السماح بإرسال/استقبال رسائل LLDP على المنفذ.
show cdp neighbors CDP عرض الأجهزة المجاورة (الأسماء والمنافذ).
show cdp neighbors detail CDP عرض تفاصيل الأجهزة المجاورة (بما فيها الـ IP).
show lldp neighbors LLDP عرض الأجهزة المجاورة باستخدام المعيار العالمي.
