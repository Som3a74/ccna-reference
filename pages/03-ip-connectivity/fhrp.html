بروتوكولات البوابة الاحتياطية (FHRP - HSRP & VRRP)

نبذة سريعة

بروتوكولات FHRP (First Hop Redundancy Protocols) بتسمحلك تعمل أكتر من راوتر كبوابة افتراضية (Default Gateway) للأجهزة. لو الراوتر الأساسي وقع، الراوتر الاحتياطي بياخد مكانه فوراً بدون ما المستخدم يحس بأي انقطاع. المنهج بيركز على HSRP (Hot Standby Router Protocol) الخاص بسيسكو، وفيه بروتوكول تاني زيه بالظبط بس معيار عالمي اسمه VRRP.

إعداد سريع (انسخ والصق)

إعداد HSRP الإصدار 2، وتحديد عنوان IP وهمي (Virtual IP)، وجعل هذا الراوتر هو الأساسي (Active):

interface g0/0
 standby version 2
 standby 1 ip 192.168.1.254
 standby 1 priority 110
 standby 1 preempt

الإعداد خطوة بخطوة

standby version 2 Interface config

Router(config-if)# Exam PT ✔

الصيغة:

standby version 2

الشرح: بيغير إصدار الـ HSRP للإصدار الثاني. ده بيسمح بأرقام جروبات أكتر وبيضيف دعم للـ IPv6. لازم كل الروترات في نفس الجروب يكونوا شغالين بنفس الإصدار.

standby ip Interface config

Router(config-if)# Exam PT ✔

الصيغة:

standby <group-number> ip <virtual-ip>

الشرح: ده أهم أمر. بيحدد الـ IP الوهمي اللي هتديه للأجهزة في الشبكة كـ Default Gateway. الرقم الوهمي ده الروترات بتتناوب عليه، اللي بيكسب بياخده لنفسه.

standby priority Interface config

Router(config-if)# Exam PT ✔

الصيغة:

standby <group-number> priority <value>

الشرح: بيحدد مين الراوتر الأساسي (Active) ومين الاحتياطي (Standby). الراوتر صاحب أعلى Priority بيكسب (عكس الـ STP). القيمة الافتراضية هي 100، فبندي الراوتر الأساسي 110 أو 150.

standby preempt Interface config

Router(config-if)# Exam PT ✔

الصيغة:

standby <group-number> preempt

الشرح: أمر مهم جداً. من غيره، لو الراوتر الأساسي وقع والاحتياطي اشتغل، وبعدين الأساسي رجع تاني.. الأساسي مش هيرجع ياخد مكانه! أمر preempt بيسمح للراوتر اللي الـ Priority بتاعته أعلى إنه يطرد الراوتر الحالي وياخد هو القيادة فوراً.

أوامر التحقق

show standby brief Privileged EXEC

Router# Exam PT ✔

الشرح: بيعرض جدول ملخص لحالة الـ HSRP، ومين الراوتر الـ Active ومين الـ Standby، والـ Virtual IP.

                     P indicates configured to preempt.
                     |

فحص الأعطال (Troubleshooting)

  • الروترين شايفين نفسهم Active: لو عملت show standby brief على الروترين ولقيتهم الاتنين كاتبين إن حالتهم Active، ده معناه إن رسائل الـ Hello مش بتوصل بينهم. غالباً السويتش اللي بيربط بينهم فيه مشكلة، أو البورتات مش في نفس الـ VLAN، أو فيه ACL مانعة الـ Multicast الخاص بـ HSRP.
  • الراوتر الأساسي لا يعود بعد إصلاحه: نسيت تكتب أمر standby preempt.

أخطاء شائعة وفخاخ الامتحان

  • الأعلى بيكسب: في التوجيه والـ HSRP، الـ Priority الأعلى بيكسب. في الـ STP، الـ Priority الأقل بيكسب.
  • الـ Virtual MAC: الـ HSRP بيكريت MAC Address وهمي عشان يرد بيه على الـ ARP بتاع الأجهزة. في الإصدار الأول الـ MAC بيبدأ بـ 0000.0c07.acXX (مكان XX هو رقم الجروب بالـ Hex). في الإصدار التاني بيبدأ بـ 0000.0C9F.FXXX. الامتحان بيحب يسأل في شكل الـ MAC ده جداً!
  • HSRP vs VRRP: الـ HSRP خاص بسيسكو وحالته بتكون (Active / Standby). الـ VRRP معيار عالمي وحالته بتكون (Master / Backup) وبيستخدم أمر vrrp بدل standby بس نفس الفكرة بالظبط.

جدول مختصر

Command الوظيفة (Purpose)
standby version 2 تفعيل الإصدار الثاني من HSRP.
standby 1 ip 192.168.1.254 تحديد الـ IP الوهمي للجروب 1.
standby 1 priority 110 رفع الأولوية لجعل الراوتر الأساسي (الافتراضي 100).
standby 1 preempt السماح للراوتر باسترجاع القيادة إذا تعافى من عطل.
show standby brief عرض ملخص للجروبات، والأدوار، والـ Virtual IP.
