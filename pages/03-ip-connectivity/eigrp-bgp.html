CCNA Reference

بروتوكولات التوجيه (EIGRP & BGP)

نبذة سريعة

ملاحظة هامة (Out of Blueprint Scope)
في المنهج الرسمي الحالي لـ CCNA 200-301، تم إلغاء أسئلة إعداد (Configuration) الخاصة بـ EIGRP و BGP تماماً. المطلوب منك فقط هو معرفة المفاهيم العامة والـ Administrative Distance الخاصة بهم. هذه الصفحة تعتبر مرجع إضافي (Bonus) للعملي ولمن يريد التوسع.

بروتوكول EIGRP هو بروتوكول توجيه متقدم خاص بسيسكو بيعتمد على سرعة الكابل والتأخير. و BGP هو بروتوكول الإنترنت الخارجي اللي بيربط الشركات بمزودي الخدمة (ISPs).

إعداد سريع (انسخ والصق)

إعداد EIGRP وإعداد eBGP لربط فرعين:

! إعداد EIGRP رقم 100
router eigrp 100
 network 10.1.1.0 0.0.0.3
 network 192.168.1.0 0.0.0.255
 no auto-summary

! إعداد BGP رقم 65000 للربط مع مزود الخدمة 65001
router bgp 65000
 neighbor 200.1.1.2 remote-as 65001
 network 192.168.1.0 mask 255.255.255.0

الإعداد خطوة بخطوة

router eigrp Global config

Router(config)# Exam PT ✔

الصيغة:

router eigrp <AS-number>
 network <network-ip> <wildcard-mask>

الشرح: رقم الـ AS في EIGRP لازم يكون متطابق على كل الروترات اللي عايزها تكلم بعض (عكس الـ OSPF Process ID). أمر الـ network بيشتغل بالـ Wildcard Mask وبيشغل البروتوكول على الفتحات اللي تقع داخل هذا الـ IP.

router bgp Global config

Router(config)# Exam PT ✔

الصيغة:

router bgp <local-AS-number>
 neighbor <neighbor-ip> remote-as <remote-AS-number>
 network <network-ip> mask <subnet-mask>

الشرح: الـ BGP بروتوكول مختلف تماماً. رقم الـ AS بيمثل شركتك ككل على الإنترنت. لازم تحدد الجار بتاعك صراحة بأمر neighbor وتقول هو في أي AS. وأمر network هنا مش بيشغل البروتوكول على فتحات! ده مجرد إعلان، بياخد شبكة موجودة فعلياً في جدول التوجيه بتاعك وينشرها للجار. ولازم يستخدم Subnet Mask (مش Wildcard) وبكلمة mask صريحة.

أوامر التحقق

show ip bgp summary Privileged EXEC

Router# Exam PT ✔

الشرح: أهم أمر في الـ BGP لمعرفة إذا كان الراوتر نجح يتصل بجاره ولا لأ.

R1# show ip bgp summary
BGP router identifier 10.1.1.1, local AS number 65000
BGP table version is 2, main routing table version 2

Neighbor        V           AS MsgRcvd MsgSent   TblVer  InQ OutQ Up/Down  State/PfxRcd
200.1.1.2       4        65001      15      15        2    0    0 00:10:35 1

إزاي تقرا الجدول: أهم عمود هو الأخير State/PfxRcd. لو لقيت مكتوب فيه رقم (زي 1 أو 0 أو 5)، ده معناه إن الاتصال تم بنجاح والرقم ده هو عدد الشبكات اللي استلمتها من الجار. لو لقيت كلمة زي Idle أو Active يبقى الاتصال واقع وفيه مشكلة!

فحص الأعطال (Troubleshooting)

  • BGP State is Active: الكلمة دي خادعة! Active في الـ BGP معناها إنه "بيحاول بنشاط" يفتح اتصال بس بيفشل (عكس الـ HSRP). المشكلة غالباً إن الـ IP بتاع الجار مكتوب غلط، أو إن البورت رقم 179 (TCP) مقفول بـ ACL.
  • EIGRP AS Mismatch: لو راوتر اتعمل بـ eigrp 100 والتاني eigrp 200 مستحيل يشوفوا بعض.
  • BGP Network Mismatch: لو أمر network في الـ BGP مكتوب فيه ماسك مختلف عن الموجود في جدول التوجيه بحرف واحد، الشبكة مش هتتنشر. لازم تطابق تام! (Exact Match).

أخطاء شائعة وفخاخ الامتحان

  • Wildcard vs Subnet Mask: الـ OSPF والـ EIGRP بيستخدموا Wildcard mask. الـ BGP بيستخدم Subnet mask ولازم تكتب كلمة mask قبلها.
  • AD Values: تذكر أن الـ AD للـ EIGRP الداخلي هو 90، وللـ eBGP هو 20.
  • وظيفة أمر Network: في EIGRP و OSPF، الأمر ده بيبحث عن الفتحات اللي الـ IP بتاعها يطابق، ويبدأ يبعت عليها رسائل Hello. في الـ BGP الأمر ملوش دعوة بالفتحات إطلاقاً، هو فقط بياخد الشبكة من الـ Routing Table ويحطها في الـ BGP Table.

جدول مختصر

Command الوظيفة (Purpose)
router eigrp <as> تفعيل EIGRP. (رقم الـ AS يجب أن يتطابق).
router bgp <as> تفعيل BGP.
neighbor <ip> remote-as <as> تحديد جار الـ BGP ورقم الـ AS الخاص به.
network <net> mask <mask> نشر شبكة في الـ BGP (يتطلب تطابق تام مع جدول التوجيه).
show ip bgp summary عرض حالة اتصال الـ BGP (تأكد من وجود رقم في العمود الأخير).
