CCNA Reference

مفاهيم الشبكات وأدوات الأساسيات

نبذة سريعة

معظم المفاهيم الأساسية في الـ CCNA (زي OSI Model، TCP/UDP، وتكوين الـ IP) هي مفاهيم نظرية ملهاش أوامر إعداد (Config). لكن فيه أوامر مهمة جداً بنستخدمها عشان نتأكد إن الأجهزة شايفة بعض في الطبقة التانية (Layer 2 - MAC) والطبقة التالتة (Layer 3 - ARP)، بالإضافة لأوامر فحص الشبكة من على أجهزة الكمبيوتر (Windows).

إعداد سريع (انسخ والصق)

الأوامر دي أوامر فحص (show) مش إعدادات. عشان كده مفيش إعداد سريع هنا، بس أهم أمر لمهندس الشبكات هو فحص جدول الـ MAC في السويتش:

show mac address-table

الأوامر خطوة بخطوة

1. جداول الطبقة الثانية (Layer 2 - Switch)

show mac address-table Privileged EXEC

Switch# Exam PT ✔

الصيغة:

show mac address-table [dynamic | interfaces <int> | vlan <id>]
clear mac address-table dynamic

الشرح: بيعرض جدول العناوين الفيزيائية (MAC) اللي السويتش اتعلمها. السويتش بيبني الجدول ده عن طريق قراءة الـ Source MAC بتاع أي رسالة بتدخله. لو عايز تفضي الجدول عشان تخليه يتعلم من أول وجديد (لو نقلت كابلات مثلاً)، بتستخدم أمر clear.

مثال:

SW1# show mac address-table dynamic
          Mac Address Table
-------------------------------------------

Vlan    Mac Address       Type        Ports
----    -----------       --------    -----
   1    0011.2233.4455    DYNAMIC     Fa0/1
  10    00aa.bbcc.dd11    DYNAMIC     Fa0/2
Total Mac Addresses for this criterion: 2

2. جداول الطبقة الثالثة والربط (Layer 3 - ARP)

show arp Privileged EXEC

Router# Exam PT ✔

الصيغة:

show arp
clear arp-cache

الشرح: بروتوكول ARP وظيفته يربط بين الـ IP والـ MAC. الراوتر أو جهاز الكمبيوتر بيستخدمه عشان يعرف الـ MAC بتاع الجهاز اللي عايز يكلمه في نفس الشبكة. أمر show arp بيعرض الجدول ده على الراوتر.

مثال:

R1# show arp
Protocol  Address          Age (min)  Hardware Addr   Type   Interface
Internet  192.168.1.1             -   0000.0c07.ac01  ARPA   GigabitEthernet0/0
Internet  192.168.1.100          12   00aa.bbcc.dd11  ARPA   GigabitEthernet0/0

3. أوامر الفحص من أجهزة الكمبيوتر (Windows CMD)

arp -a Windows CMD

C:\> Exam PT ✔

الصيغة:

arp -a
arp -d *

الشرح: أمر arp -a بيعرض جدول الـ ARP الخاص بجهاز الويندوز نفسه. وأمر arp -d * بيمسح الجدول ده بالكامل، وده مفيد لو كان الجهاز مخزن MAC غلط بعد ما إنت غيرت كارت الشبكة بتاع الراوتر مثلاً والكمبيوتر لسة بيحاول يكلم الـ MAC القديم.

ipconfig Windows CMD

C:\> Exam PT ✔

الصيغة:

ipconfig
ipconfig /all
ipconfig /release
ipconfig /renew

الشرح:

  • ipconfig: بيعرض الـ IP، الـ Subnet Mask، والـ Default Gateway.
  • ipconfig /all: بيجيب تفاصيل أكتر زي الـ MAC address بتاع الكمبيوتر (اسمه Physical Address) والـ DNS.
  • ipconfig /release ثم ipconfig /renew: بيمسح الـ IP اللي الكمبيوتر واخده من الـ DHCP ويطلب واحد جديد. مهم جداً وقت فحص مشاكل الـ IP.

nslookup Windows CMD

C:\> Exam PT ✔

الصيغة:

nslookup <domain-name>

الشرح: بيسأل الـ DNS سيرفر عشان يحول اسم موقع (زي google.com) لـ IP address. لو الأمر رجع خطأ، يبقى الكمبيوتر مش قادر يوصل للـ DNS أو إعداداته غلط.

مثال:

C:\> nslookup cisco.com
Server:  UnKnown
Address:  8.8.8.8

Non-authoritative answer:
Name:    cisco.com
Addresses:  2001:420:1101:1::a
          72.163.4.185

فحص الأعطال (Troubleshooting)

مشكلة MAC Flapping

لو لاحظت رسالة في السويتش بتقول %SW_MATM-4-MACFLAP_NOTIF: Host 0011.2233.4455 in vlan 1 is flapping between port Fa0/1 and port Fa0/2، ده معناه إن السويتش بيشوف نفس الـ MAC مرة جاي من بورت 1 ومرة جاي من بورت 2. السبب الرئيسي: وجود Loop في الشبكة (مفيش Spanning Tree شغال)، أو فيه جهازين واخدين نفس الـ MAC بالغلط.

مشكلة ARP Spoofing / IP Conflict

لو جهازين في الشبكة أخدوا نفس الـ IP، جدول الـ ARP هيبدأ يتلخبط بين اتنين MAC Addresses لنفس الـ IP، وده بيوقع الاتصال. بتقدر تكتشف ده لو عملت arp -a كذا مرة ولقيت الـ MAC بتاع الراوتر بيتغير كل شوية، ده معناه إن فيه جهاز تاني (أو هاكر) بينتحل شخصية الراوتر.

أخطاء شائعة وفخاخ الامتحان

  • أمر ARP: في الراوتر بنكتب show arp، لكن في شاشة الويندوز بنكتب arp -a. الامتحان بيلعب على اللخبطة دي كتير.
  • مكان الجدول: جدول الـ MAC موجود فقط في السويتشات (L2)، وجدول الـ ARP موجود في أي جهاز بيفهم IPs زي الراوتر والكمبيوتر والـ Layer 3 Switch. السويتش العادي (Layer 2) ملوش دعوة بجدول الـ ARP بتاع الترافيك العادي.

جدول مختصر

Command الجهاز الوظيفة (Purpose)
show mac address-table Switch عرض العناوين الفيزيائية والبورتات المتصلة بها.
show arp Router عرض جدول الربط بين الـ IP والـ MAC.
arp -a Windows PC عرض جدول الربط (ARP) الخاص بالكمبيوتر.
ipconfig /all Windows PC عرض كل تفاصيل كارت الشبكة والـ MAC والـ DNS.
nslookup Windows PC اختبار قدرة الجهاز على تحويل الأسماء إلى IPs.
