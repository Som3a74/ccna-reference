عناوين IPv6 وإعدادات المنافذ

نبذة سريعة

عناوين IPv6 بتختلف عن IPv4 في إنها بتنكتب بصيغة الـ Hex، ومفيهاش قناع شبكة (Subnet Mask) صريح لكن بتستخدم الـ Prefix (زي /64). الميزة الأهم إن أي منفذ بياخد IP عالمي (Global) بيولّد لنفسه أوتماتيك عنوان محلي (Link-Local) بيبدأ بـ FE80 عشان الأجهزة المجاورة تكلمه بيه.

إعداد سريع (انسخ والصق)

عشان تشغل الـ IPv6 على الراوتر وتدي منفذ عنوان ثابت (أهم خطوة هي تفعيل التوجيه أولاً):

ipv6 unicast-routing
interface g0/0
 ipv6 address 2001:DB8:ACAD:1::1/64
 no shutdown

الإعداد خطوة بخطوة

ipv6 unicast-routing Global config

Router(config)# Exam PT ✔

الصيغة:

ipv6 unicast-routing

الشرح: أهم أمر في IPv6. رواتر سيسكو مقفول عليها توجيه الـ IPv6 افتراضياً. لو معملتش الأمر ده، الراوتر هيتعامل مع المنافذ بتاعته كأنها جهاز كمبيوتر عادي (Host)، ومش هيبعت بيانات لشبكات تانية، ومش هيبعت رسائل RA للأجهزة عشان يوزع IPs بنظام الـ (SLAAC).

ipv6 address Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ipv6 address <ipv6-address>/<prefix>

إيه اللي بنحطه مكان القيم:

  • <ipv6-address> = العنوان العالمي (Global Unicast Address).
  • <prefix> = حجم الشبكة، وغالباً بيكون 64.

مثال:

R1(config-if)# ipv6 address 2001:DB8:ACAD:1::1/64

ipv6 address eui-64 Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ipv6 address <ipv6-prefix>/<prefix> eui-64

الشرح: بدل ما تكتب الـ IP كله بإيدك، بتكتب عنوان الشبكة بس (أول 64 بت)، والراوتر بيكمل النص التاني (آخر 64 بت) لوحده باستخدام الـ MAC Address بتاع المنفذ بعد ما يقلب البت السابع (7th bit) ويحط FFFE في النص. دي طريقة عشان تتأكد إن الـ IP فريد ومبيتكررش.

مثال:

R1(config-if)# ipv6 address 2001:DB8:ACAD:2::/64 eui-64

ipv6 address autoconfig Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ipv6 address autoconfig

الشرح: بيخلي المنفذ يتصرف كـ Client ويسحب الـ IP العالمي بتاعه والـ Gateway من راوتر تاني باستخدام رسائل Router Advertisement (RA) بنظام SLAAC.

ipv6 enable Interface config

Router(config-if)# Exam PT ✔

الصيغة:

ipv6 enable

الشرح: لو كتبت الأمر ده، المنفذ هيولّد عنوان محلي (Link-Local) يبدأ بـ FE80 فقط بناءً على الـ MAC Address تاعه، ومش هياخد عنوان عالمي. الأمر ده بيستخدم لو إنت عايز تشغل بروتوكولات التوجيه (زي OSPFv3) من غير ما تدي للرواتر IPs عالمية، كنوع من توفير العناوين والحماية.

أوامر التحقق

1. show ipv6 interface brief

الأمر الأساسي. بيوريك إن كل منفذ شغال أخد عنوانين: الأول Link-Local (بيبدأ بـ FE80) والتاني Global (الرقم اللي إنت كتبته).

R1# show ipv6 interface brief
GigabitEthernet0/0     [up/up]
    FE80::201:C9FF:FE11:2233
    2001:DB8:ACAD:1::1
GigabitEthernet0/1     [administratively down/down]
    unassigned

2. show ipv6 interface

أمر بيعرض تفاصيل أكتر، وأهمها إنه بيوريك مجموعات الـ Multicast اللي المنفذ منضم ليها (مثلاً FF02::1 لكل الأجهزة و FF02::2 لكل الرواتر).

R1# show ipv6 interface g0/0
GigabitEthernet0/0 is up, line protocol is up
  IPv6 is enabled, link-local address is FE80::201:C9FF:FE11:2233 
  Global unicast address(es):
    2001:DB8:ACAD:1::1, subnet is 2001:DB8:ACAD:1::/64
  Joined group address(es):
    FF02::1
    FF02::2
    FF02::1:FF00:1

فحص الأعطال (Troubleshooting)

الأجهزة مش بتسحب IPv6 (SLAAC مش شغال)

لو فعلت الـ IP على واجهة الراوتر والأجهزة (الكمبيوترات) مش راضية تسحب أرقام، المشكلة بنسبة 99% إنك نسيت تكتب أمر ipv6 unicast-routing على الراوتر من برة (Global config). الراوتر من غيره مش بيبعت رسايل RA للأجهزة.

أخطاء شائعة وفخاخ الامتحان

  • عنوان EUI-64: في الامتحان، هيجيبلك الـ MAC (مثلاً 0000.1111.2222) ويطلب منك تتوقع الـ Link-Local. هتقسم الـ MAC نصين وتحط FFFE في النص وتقلّب البت السابع. الـ 00 في الهيكسا هتبقى 02. الإجابة هتكون FE80::0200:11FF:FE11:2222.
  • ipv6 enable: الأمر ده مش بيدي IP عالمي، هو بيكتفي بالـ Link-Local فقط. لو عايز تدي IP عالمي، استخدم ipv6 address، وهو هيولد الـ Link-Local تلقائياً ومفيش داعي تكتب ipv6 enable معاه.

جدول مختصر

Command الوظيفة (Purpose)
ipv6 unicast-routing تفعيل توجيه الـ IPv6 والسماح للراوتر بتوزيع العناوين.
ipv6 address <ipv6>/<prefix> إعطاء المنفذ عنوان عالمي (Global Unicast) ثابت.
ipv6 address <prefix> eui-64 إعطاء المنفذ عنوان، واستنتاج النصف الثاني من الـ MAC.
ipv6 address autoconfig سحب عنوان للمنفذ من راوتر آخر (نظام SLAAC).
ipv6 enable توليد عنوان Link-Local فقط بدون عنوان عالمي.
show ipv6 interface brief التحقق من عناوين المنفذ (Link-Local و Global).
