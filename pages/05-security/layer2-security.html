حماية الطبقة الثانية (Layer 2 Security)

نبذة سريعة

تعتبر الطبقة الثانية (Data-Link Layer) من أخطر نقاط الضعف في الشبكة المحلية، لأن البروتوكولات القديمة مثل ARP و DHCP صُممت بدون أي آليات تحقق ومصادقة ذاتية. توفر سيسكو ثلاثة أسلحة دفاعية رئيسية في السويتشات (موضوع أساسي في امتحان CCNA 200-301):

  • 1. Port Security: حماية منافذ السويتش من هجمات إغراق جدول العناوين (MAC Table Flooding) ومنع توصيل أجهزة غير مصرح بها عن طريق تحديد عدد الماك أدرس المسموح بها وخاصية الحفظ التلقائي (Sticky MAC).
  • 2. DHCP Snooping: الحماية من خوادم الـ DHCP المزيفة (Rogue DHCP Servers) وهجمات استنزاف العناوين (DHCP Starvation). يقسم المنافذ إلى موثوقة (Trusted) متصلة بالسيرفر الحقيقي، وغير موثوقة (Untrusted) تسقط أي رسائل Offer أو Ack قادمة من المستخدمين. ويبني جدول ربط ديناميكي (DHCP Snooping Binding Database).
  • 3. Dynamic ARP Inspection (DAI): الحماية من هجمات التسميم وانتحال عناوين الـ ARP (ARP Poisoning / Man-in-the-Middle). يعتمد على فحص حزم الـ ARP ومقارنة الـ IP والـ MAC الخاص بها مع جدول الـ DHCP Snooping، وإسقاط أي حزمة مزيفة فوراً.
  • أوضاع العقاب في Port Security:
    • Shutdown (الافتراضي): إسقاط الحزمة، إرسال تنبيه Syslog/SNMP، وقفل المنفذ تماماً في وضع err-disabled.
    • Restrict: إسقاط الحزمة، إرسال تنبيه Syslog/SNMP، وزيادة عداد الانتهاكات (Violation Counter) مع بقاء المنفذ يعمل.
    • Protect: إسقاط الحزمة بصمت تام وبدون إرسال أي تنبيه وبدون زيادة العداد مع بقاء المنفذ يعمل.

إعداد سريع (انسخ والصق)

إعداد شامل لتفعيل Port Security مع Sticky MAC، وتفعيل DHCP Snooping و DAI على شبكة VLAN 10:

! 1. إعداد Port Security على منافذ المستخدمين
interface range FastEthernet0/1 - 24
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address sticky
 switchport port-security violation restrict

! 2. تفعيل DHCP Snooping وحماية الشبكة
ip dhcp snooping
ip dhcp snooping vlan 10
no ip dhcp snooping information option

! تحديد المنفذ الصاعد للسيرفر كموثوق به (Trusted)
interface GigabitEthernet0/1
 ip dhcp snooping trust

! 3. تفعيل Dynamic ARP Inspection (DAI)
ip arp inspection vlan 10
ip arp inspection validate src-mac dst-mac ip

! تحديد المنفذ الصاعد كـ Trusted للـ ARP
interface GigabitEthernet0/1
 ip arp inspection trust

الإعداد خطوة بخطوة

maximum & mac-address sticky MAC Learning

Switch(config-if)# Exam PT ✔

الصيغة:

switchport port-security maximum <1-8192>
switchport port-security mac-address sticky

الشرح: الأمر maximum يحدد أقصى عدد ماك أدرس مسموح بها على هذا المنفذ (الافتراضي 1). والأمر mac-address sticky يجعل السويتش يتعلم الماك أدرس لأول جهاز يتصل ويثبته تلقائياً في ملف الإعدادات الجاري (Running-Config)، مما يوفر عناء كتابة الماك أدرس يدوياً لكل مستخدم.

switchport port-security violation Action on Violation

Switch(config-if)# Exam PT ✔

الصيغة:

switchport port-security violation {shutdown | restrict | protect}

مقارنة الأوضاع للامتحان:

  • shutdown (الوضع الافتراضي): يقفل المنفذ فوراً (err-disabled)، يولد تنبيه Syslog و SNMP Trap، ويزيد عداد الانتهاكات.
  • restrict: يسقط حزم المهاجم فقط، يبقي المنفذ يعمل لباقي الأجهزة المصرح لها، يولد تنبيه Syslog و SNMP Trap، ويزيد عداد الانتهاكات.
  • protect: يسقط حزم المهاجم فقط، لا يولد أي تنبيه، ولا يزيد العداد (صامت تماماً).

errdisable recovery Automatic Port Recovery

Switch(config)# Exam PT ✔

الصيغة:

! تفعيل الاستعادة التلقائية لانتهاكات الـ Port Security
errdisable recovery cause psecure-violation
errdisable recovery interval <30-86400-seconds>

! يدوياً (إذا لم تفعل الاستعادة التلقائية):
interface <interface-id>
 shutdown
 no shutdown

الشرح: عندما يقفل المنفذ بوضع err-disabled، يحتاج المهندس للدخول وكتابة shutdown ثم no shutdown لإعادة تشغيله. تفعيل هذا الأمر يجعل السويتش يعيد فتح المنفذ تلقائياً بعد انقضاء الوقت المحدد بالثواني (مثلاً 300 ثانية).

ip dhcp snooping Rogue DHCP Defense

Switch(config)# & (config-if)# Exam PT ✔

الصيغة:

! 1. تفعيل الخاصية على مستوى السويتش
ip dhcp snooping

! 2. تحديد الفيلانات المحمية
ip dhcp snooping vlan <vlan-list>

! 3. إلغاء Option 82 في بيئات Layer 2 البسيطة (مهم جداً!)
no ip dhcp snooping information option

! 4. تحديد المنافذ الموثوقة (المتصلة بالسيرفر الأصلي أو سويتش صاعد)
interface <uplink-interface>
 ip dhcp snooping trust

! 5. تحديد حد أقصى لمعدل الحزم على منافذ المستخدمين لمنع DoS
interface range <access-interfaces>
 ip dhcp snooping limit rate <1-2048-pps>

الشرح: السويتش يعتبر جميع المنافذ غير موثوقة (Untrusted) افتراضياً، ويسقط أي رسائل خادم (DHCPOFFER و DHCPACK) قادمة منها لحماية المستخدمين من استلام أيبيهات وبوابات مزورة.

ip arp inspection (DAI) ARP Spoofing / MitM Defense

Switch(config)# & (config-if)# Exam PT ✔

الصيغة:

! 1. تفعيل فحص الـ ARP على الفيلان (يتطلب تفعيل DHCP Snooping مسبقاً)
ip arp inspection vlan <vlan-list>

! 2. تحديد المنفذ الصاعد كموثوق (Trusted)
interface <uplink-interface>
 ip arp inspection trust

! 3. تفعيل التحقق الإضافي من ترويسات MAC و IP
ip arp inspection validate src-mac dst-mac ip

الشرح: هجوم تسميم الـ ARP (ARP Poisoning) يخدع الضحية ليظن أن جهاز المهاجم هو الراوتر (Default Gateway). خاصية DAI تفحص كل حزمة ARP تمر عبر منافذ المستخدمين؛ فإذا لم يتطابق الـ MAC والـ IP مع جدول الـ DHCP Snooping Binding Table، يتم إسقاط الحزمة وتسجيل محاولة الاختراق فوراً.

switchport nonegotiate VLAN Hopping Mitigation

Switch(config-if)# Exam PT ✔

الصيغة:

! 1. إغلاق بروتوكول DTP على منافذ المستخدمين لمنع Switch Spoofing
interface range <access-ports>
 switchport mode access
 switchport nonegotiate

! 2. حماية منافذ الـ Trunk من هجوم Double Tagging
interface <trunk-port>
 switchport mode trunk
 switchport trunk native vlan 999

الشرح: هجمات القفز بين الفيلانات (VLAN Hopping) تتم بطريقتين: إما انتحال السويتش (Switch Spoofing) باستغلال تفاوض DTP، ويتم إحباطه بأمر switchport nonegotiate. أو استغلال الفيلان الأصلية (Double Tagging)، ويتم إحباطه بتغيير الـ Native VLAN إلى رقم فيلان وهمية غير مستخدمة لأي أجهزة (مثل VLAN 999).

فحص الأعطال (Troubleshooting)

  • المنفذ تحول إلى وضع err-disabled وتوقفت لمبته عن العمل:
    1. افحص حالة المنفذ بأمر show interfaces status err-disabled.
    2. إذا كان السبب psecure-violation، افحص الماك أدرس المتصل حالياً بالمنفذ؛ تم توصيل جهاز إضافي أو تغيير الجهاز المصرح له.
    3. لإعادة التشغيل: افصل الجهاز المعتدي، ثم ادخل للمنفذ واكتب shutdown ثم no shutdown.
  • الأجهزة عاجزة عن سحب IP من الـ DHCP بعد تفعيل Snooping:
    1. أشهر خطأ على الإطلاق: هل نسيت تحديد المنفذ الصاعد لسيرفر الـ DHCP كـ Trusted؟ ادخل للمنفذ واكتب ip dhcp snooping trust.
    2. إذا كان السويتش من الطبقة الثانية بدون IP Routing، فإن إضافة الـ Option 82 تجعل الراوتر أو السيرفر يسقط الطلب! اكتب في السويتش: no ip dhcp snooping information option.
  • الأجهزة ذات الـ IP الثابت (Static IP) مقطوعة تماماً بسبب DAI:
    1. خاصية DAI تعتمد على جدول DHCP Snooping، والأجهزة ذات العناوين الثابتة (مثل الطابعات أو السيرفرات) ليس لها سجل في هذا الجدول!
    2. الحل: إنشاء ARP ACL خاصة وتطبيقها عبر أمر ip arp inspection filter <acl-name> vlan <vlan-id> لتوثيق الأيبيهات الثابتة يدوياً.

أخطاء شائعة وفخاخ الامتحان

  • جدول مقارنة أوضاع Violation في Port Security:
    الوضع (Mode) حالة المنفذ (Port State) إسقاط الترافيك (Drop Traffic) تسجيل في السجلات (Syslog/Trap) زيادة العداد (Violation Counter)
    Shutdown (الافتراضي) err-disabled (يقفل تماماً) نعم نعم نعم
    Restrict يعمل (Up) نعم (حزم المهاجم فقط) نعم نعم
    Protect يعمل (Up) نعم (حزم المهاجم فقط) لا (صامت) لا (صامت)
  • أنواع الماك أدرس في Port Security:
    • Static: تتم برمجته يدوياً بأمر switchport port-security mac-address <mac> ويحفظ في الـ Running-Config.
    • Dynamic: يتعلمه السويتش ديناميكياً عند وصول أول إطار، ويخزن في الرام فقط ويختفي عند إعادة تشغيل السويتش.
    • Sticky: يتعلمه السويتش ديناميكياً ثم يحوله فوراً إلى سطر في الـ Running-Config، فإذا حفظت الإعدادات (write) يبقى ثابتاً حتى بعد إعادة التشغيل.
  • ترتيب تفعيل التقنيات:

    لا يمكنك تفعيل Dynamic ARP Inspection (DAI) بنجاح بدون تفعيل DHCP Snooping أولاً، لأن DAI يعتمد كلياً على قاعدة بيانات الـ Snooping للتحقق من العناوين!

  • فخ الـ Native VLAN في Trunk Ports:

    في هجوم الـ Double Tagging، يستغل المهاجم أن السويتش يرسل إطارات الـ Native VLAN بدون ترويسة 802.1Q (Untagged). لحل هذه الثغرة، يجب تغيير الـ Native VLAN لرقم غير مستخدم، أو كتابة الأمر الشامل: vlan dot1q tag native لإجبار السويتش على وضع Tag للـ Native VLAN أيضاً.

جدول مختصر

Command Mode الوظيفة (Purpose)
switchport port-security Interface config تفعيل خاصية أمان المنفذ على واجهة Access.
switchport port-security maximum <n> Interface config تحديد أقصى عدد من عناوين MAC المسموح بها على المنفذ.
switchport port-security mac-address sticky Interface config التعلم التلقائي للماك أدرس وتثبيته في ملف الإعدادات.
switchport port-security violation {mode} Interface config تحديد وضع التعامل مع المخالفات (Shutdown أو Restrict أو Protect).
ip dhcp snooping Global config تفعيل خاصية الحماية من سيرفرات الـ DHCP المزيفة على السويتش.
ip dhcp snooping vlan <id> Global config تحديد الفيلانات المحمية بتقنية الـ DHCP Snooping.
ip dhcp snooping trust Interface config تعيين المنفذ كمنفذ موثوق به لاستقبال رسائل خوادم الـ DHCP.
ip arp inspection vlan <id> Global config تفعيل فحص الـ ARP الديناميكي (DAI) لمنع هجمات التسميم.
ip arp inspection trust Interface config تعيين المنفذ كموثوق به لتمرير حزم الـ ARP بدون فحص.
show port-security interface <int> Privileged EXEC عرض حالة أمان المنفذ وعدد الانتهاكات وعناوين MAC المسجلة.
show ip dhcp snooping binding Privileged EXEC عرض جدول ربط الـ IP والـ MAC والمنافذ التي وزعها الـ DHCP.
