نظام AAA وتقوية الأجهزة (AAA & Hardening)

نبذة سريعة

في شبكات المؤسسات الكبرى، من المستحيل إدارة حسابات وكلمات مرور المهندسين محلياً على كل راوتر وسويتش على حدة. نظام AAA (Authentication, Authorization, Accounting) يوفر إدارة أمنية مركزية متكاملة:

  • أركان الـ AAA الثلاثة:
    • المصادقة (Authentication - من أنت؟): التحقق من هوية المستخدم وكلمة مروره عبر خادم مركزي مثل Cisco ISE.
    • التفويض (Authorization - ماذا يحق لك أن تفعل؟): تحديد الصلاحيات ومستوى الوصول (Privilege Level) والأوامر المسموح للمهندس بتنفيذها على الـ CLI.
    • المحاسبة والتدقيق (Accounting - ماذا فعلت؟): تسجيل وتوثيق كل أمر كتبه المستخدم ووقت بداية ونهاية جلسته لضمان الرقابة والمساءلة.
  • مقارنة TACACS+ مقابل RADIUS (سؤال مضمون في الامتحان):
    • TACACS+ (سيسكو): يعتمد على TCP Port 49. يفصل تماماً بين الـ Authentication والـ Authorization والـ Accounting. يشفر محتوى الحزمة بالكامل (Full Payload Encryption). مخصص لإدارة الأجهزة (Device Administration).
    • RADIUS (معيار مفتوح): يعتمد على UDP Ports 1812/1813. يدمج المصادقة والتفويض معاً. يشفر كلمة المرور فقط وباقي الحزمة نص صريح. مخصص للتحكم في وصول المستخدمين للشبكة (Network Access مثل 802.1X و VPN).
  • قائمة الطرق (Method List) والاحتياط المحلي (Fallback): نحدد فيها السيرفر المركزي أولاً، ثم كلمة local احتياطياً لتمكين الدخول إذا انقطع الاتصال بالسيرفر المركزي.

إعداد سريع (انسخ والصق)

تفعيل نموذج AAA الحديث وربط الراوتر بخادم TACACS+ مع توفير حساب محلي للطوارئ:

! 1. إنشاء حساب محلي للطوارئ في حال سقوط السيرفر
username admin_rescue privilege 15 secret RescuePass#2026

! 2. تفعيل نموذج الـ AAA الحديث
aaa new-model

! 3. تعريف خادم الـ TACACS+ (أو Cisco ISE)
tacacs server ISE-SERVER
 address ipv4 192.168.1.100
 key TacacsKeySecret123!

! 4. إضافة السيرفر لمجموعة
aaa group server tacacs+ TACACS-GRP
 server name ISE-SERVER

! 5. تطبيق قوائم الطرق مع Fallback للحساب المحلي
aaa authentication login default group TACACS-GRP local
aaa authorization exec default group TACACS-GRP local
aaa accounting exec default start-stop group TACACS-GRP
aaa accounting commands 15 default start-stop group TACACS-GRP

! 6. تأمين خطوط الاتصال بـ SSHv2 فقط
line vty 0 4
 transport input ssh
 login authentication default

الإعداد خطوة بخطوة

aaa new-model Enable AAA Framework

Router(config)# Exam PT ✔

الصيغة:

aaa new-model

الشرح: الخطوة الأولى الإلزامية لتفعيل بنية الـ AAA على أجهزة سيسكو. بدون كتابة هذا الأمر، لن تظهر أي من أوامر الـ AAA الأخرى في الـ CLI.

tacacs / radius server Server Definition

Router(config)# Exam PT ✔

الصيغة:

! تعريف خادم TACACS+ (نظام IOS الحديث):
tacacs server <server-name>
 address ipv4 <ip-address>
 key <shared-secret>

! تعريف خادم RADIUS:
radius server <server-name>
 address ipv4 <ip-address>
 key <shared-secret>

الشرح: تحديد عنوان IP خادم الـ AAA المركزي (مثل Cisco Identity Services Engine - ISE) ومفتاح التشفير المشترك (Shared Secret) المستخدم لحماية الاتصال بين الراوتر والخادم.

aaa group server Server Grouping

Router(config)# Exam PT ✔

الصيغة:

aaa group server tacacs+ <group-name>
 server name <server-name-1>
 server name <server-name-2>

الشرح: تجميع أكثر من خادم TACACS+ أو RADIUS داخل مجموعة واحدة لتحقيق الوفرة العالية (High Availability / Redundancy)، بحيث إذا لم يستجب السيرفر الأول يجرب الراوتر السيرفر الثاني تلقائياً.

aaa authentication login Login Method List

Router(config)# Exam PT ✔

الصيغة:

aaa authentication login {default | <list-name>} method1 [method2] [method3]

أمثلة شائعة:

! التحقق عبر TACACS+ أولاً، وإذا كان السيرفر ساقطاً نرجع للحساب المحلي:
aaa authentication login default group TACACS-GRP local

! التحقق عبر قاعدة بيانات الراوتر المحلية فقط:
aaa authentication login default local

قاعدة الـ Fallback الهامة: الراوتر يرجع للطريقة الثانية (local) فقط إذا كان السيرفر الأول غير متاح أو لا يستجيب (Unreachable / Timeout). أما إذا رد السيرفر بالرفض (Credentials Incorrect)، فسيتم رفض المستخدم فوراً ولن يجرب الطريقة الثانية!

aaa authorization exec & commands Command Permissions

Router(config)# Exam PT ✔

الصيغة:

! تفويض صلاحيات بدء جلسة الـ EXEC ومستوى الصلاحية
aaa authorization exec default group <group-name> local

! تفويض كل أمر يكتبه المهندس في وضع الـ Enable (Privilege 15)
aaa authorization commands 15 default group <group-name> local

الشرح: عندما يكتب المهندس أي أمر (مثل reload)، يسأل الراوتر سيرفر TACACS+: "هل مسموح لهذا المستخدم بتنفيذ هذا الأمر؟" فإذا رفض السيرفر، يمنع الراوتر تنفيذ الأمر على الفور.

aaa accounting Action Auditing

Router(config)# Exam PT ✔

الصيغة:

! تسجيل بدء ونهاية الجلسات
aaa accounting exec default start-stop group <group-name>

! تسجيل كل أمر يكتبه المهندس
aaa accounting commands 15 default start-stop group <group-name>

الشرح: إرسال سجلات تدقيق تفصيلية لسيرفر الـ AAA المركزي تشمل: اسم المستخدم، الـ IP الذي اتصل منه، وقت تسجيل الدخول والخروج، وكل أمر تم تنفيذه بالدقيقة والثانية.

crypto key generate rsa SSHv2 Secure Remote Access

Router(config)# Exam PT ✔

الصيغة:

! 1. تحديد اسم الجهاز واسم النطاق (إجباري قبل توليد المفاتيح)
hostname R1
ip domain-name mycorp.local

! 2. توليد مفاتيح تشفير RSA بحجم 2048 بت
crypto key generate rsa modulus 2048

! 3. إجبار الجهاز على استخدام SSH الإصدار الثاني فقط
ip ssh version 2
ip ssh time-out 60
ip ssh authentication-retries 3

! 4. إغلاق الـ Telnet تماماً وحصر الدخول على الـ SSH
line vty 0 4
 transport input ssh

الشرح: بروتوكول Telnet ينقل كلمات المرور بنص صريح (Plaintext) غير مشفر. معايير سيسكو تشترط حظر Telnet وتفعيل SSHv2 بمفتاح تشفير 2048 بت.

أوامر التحقق والمراقبة

show aaa servers Privileged EXEC

Router# show aaa servers

Router# Exam PT ✔

الشرح: فحص إصدار الـ SSH والتأكد من أنه الإصدار الثاني (Version 2.0) ومراجعة إعدادات المهلة والمحاولات.

Router# show ip ssh

فحص الأعطال (Troubleshooting)

  • المهندسون لا يستطيعون الدخول بعد تفعيل الـ AAA (Lockout):
    1. أخطر خطأ يقع فيه المهندسون! تأكد دائماً من إنشاء حساب محلي للطوارئ (username ... privilege 15 secret ...) قبل تفعيل aaa new-model.
    2. تأكد من إضافة كلمة local كطريقة احتياطية ثانية في الـ Method List.
    3. إذا تم قفل الجهاز، يمكنك الدخول حصرياً عبر الـ Console الفيزيائي إذا لم تكن الـ Console مرتبطة بالقائمة الافتراضية.
  • السيرفر لا يستجيب وتأخير طويل عند محاولة الدخول:
    1. افحص وصول البينج لسيرفر الـ AAA.
    2. تأكد من فتح منفذ TCP 49 للـ TACACS+، أو منافذ UDP 1812/1813 للـ RADIUS في الجدران النارية والـ ACLs.
    3. تأكد من تطابق الـ Shared Secret بدقة شديدة بين الراوتر والسيرفر؛ فعدم تطابقها يؤدي لرفض التوثيق بصمت.
  • فشل توليد مفاتيح RSA للـ SSH:
    1. أمر crypto key generate rsa يفشل إذا لم يكن الجهاز يحمل اسماً خاصاً غير الاسم الافتراضي (hostname) أو إذا لم يكن هناك نطاق محدد عبر ip domain-name.

أخطاء شائعة وفخاخ الامتحان

  • جدول المقارنة الحاسم للامتحان: TACACS+ مقابل RADIUS:
    المعيار TACACS+ RADIUS
    الملكية (Standard) سيسكو (Cisco Proprietary) معيار عالمي مفتوح (IETF RFC 2865)
    بروتوكول النقل والمنافذ TCP Port 49 UDP Ports 1812 & 1813 (أو قديم 1645/1646)
    التشفير (Encryption) يشفر الحزمة بالكامل (Full Packet Body) يشفر كلمة المرور فقط (Password Only)
    الفصل بين الوظائف يفصل تماماً بين Authentication و Authorization و Accounting يدمج Authentication و Authorization معاً
    الاستخدام النموذجي إدارة الراوترات والسويتشات والـ CLI التحكم في وصول المستخدمين (802.1X و VPN)
  • فخ الـ Local Fallback:

    كلمة local في نهاية قائمة الطرق لا تفحص الحساب المحلي إلا إذا كان السيرفر غائباً تماماً (No Response). إذا أدخل المستخدم كلمة سر خاطئة، يرفضه السيرفر وينتهي الفحص فوراً!

  • مستويات الصلاحيات (Privilege Levels):
    • Privilege 1: وضع المستخدم العادي (User EXEC Mode - الرمز >).
    • Privilege 15: وضع المسؤول الكامل (Privileged EXEC Mode - الرمز #) بصلاحيات تحكم تامة.

جدول مختصر

Command Mode الوظيفة (Purpose)
aaa new-model Global config تفعيل إطار عمل الـ AAA الحديث على الجهاز.
tacacs server <name> Global config تعريف خادم TACACS+ وتحديد عنوان الـ IP والمفتاح المشترك.
radius server <name> Global config تعريف خادم RADIUS وتحديد عنوان الـ IP والمفتاح المشترك.
aaa authentication login default ... Global config تحديد طرق التحقق من تسجيل الدخول مع خيار الاحتياط المحلي.
aaa authorization exec default ... Global config تفويض صلاحيات الدخول لمستوى الـ EXEC عبر السيرفر.
aaa accounting commands 15 ... Global config تسجيل وتدقيق كل أمر يتم تنفيذه في المستوى 15.
crypto key generate rsa modulus 2048 Global config توليد مفاتيح تشفير RSA بطول 2048 بت لبروتوكول SSH.
show aaa servers Privileged EXEC عرض حالة خوادم الـ AAA وإحصائيات الحزم المستلمة والمرسلة.
