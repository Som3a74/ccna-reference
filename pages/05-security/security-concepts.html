مفاهيم الحماية وتقوية الأجهزة (Security Concepts)

نبذة سريعة

الأمن السيبراني في شبكات المؤسسات لا يقتصر على برامج مكافحة الفيروسات، بل هو منظومة متكاملة تبدأ من فهم التهديدات وتنتهي بتطبيق سياسات التقوية (Hardening) على كل راوتر وسويتش في الشبكة:

  • مثلث الحماية (CIA Triad):
    • السرية (Confidentiality): منع الوصول غير المصرح به للبيانات عبر التشفير (مثل AES و 3DES).
    • التكاملية وسلامة البيانات (Integrity): ضمان عدم تعديل البيانات أثناء نقلها عبر دوال التجزئة (Hashing مثل SHA-256 و HMAC).
    • التوافر والجاهزية (Availability): ضمان وصول المستخدمين المصرح لهم للخدمات بدون انقطاع عبر تقنيات التكرارية والوفرة (Redundancy كـ FHRP و STP) والحماية من هجمات DoS.
  • المصطلحات الأساسية للامتحان:
    • Threat (التهديد): الخطر أو الهجوم المحتمل الذي يهدد استقرار الشبكة.
    • Vulnerability (الثغرة): نقطة ضعف في نظام التشغيل أو التطبيق أو الإعدادات أو العامل البشري.
    • Exploit (الاستغلال): الكود أو الآلية البرمجية التي يستغل بها المهاجم الثغرة لاختراق النظام.
    • Risk (الخطر): احتمال حدوث الهجوم مضروباً في حجم الضرر الناتج عنه (Risk = Threat × Vulnerability).
    • Mitigation (الحد من المخاطر): الإجراءات والتدابير الدفاعية لتطويق وتقليل الخطر.
  • أنواع الهجمات: الاستطلاعية (Reconnaissance)، هجمات الوصول وكسر كلمات المرور (Access Attacks)، حجب الخدمة (DoS & DDoS)، وهجمات الهندسة الاجتماعية (Social Engineering كالـ Phishing).
  • بدائل كلمات المرور والتحقق: المصادقة متعددة العوامل (MFA)، الشهادات الرقمية (PKI / X.509)، والبصمات الحيوية (Biometrics).

إعداد سريع (انسخ والصق)

تطبيق حزمة التقوية الأمنية المبدئية لحماية الراوتر أو السويتش من الاختراق وهجمات التخمين:

! 1. حظر هجمات التخمين Brute-Force (حظر 120 ثانية بعد 3 محاولات فاشلة خلال 60 ثانية)
login block-for 120 attempts 3 within 60
login on-failure log
login on-success log

! 2. فرض حد أدنى لطول كلمات المرور وتشفير كلمات السر في الـ Config
security passwords min-length 10
service password-encryption
enable algorithm-type sha256 secret CiscoAdminSecure#2026

! 3. تأمين منافذ التحكم Console و VTY مع مهلة خمول 5 دقائق
line con 0
 exec-timeout 5 0
 logging synchronous
line vty 0 4
 exec-timeout 5 0
 transport input ssh
 logging synchronous
line aux 0
 no exec

! 4. إضافة رسالة تحذير قانونية (Banner MOTD)
banner motd ^
****************************************************************
* WARNING: Authorized Access Only!                             *
* All activities are monitored and logged.                     *
* Disconnect immediately if you are not an authorized user.   *
****************************************************************
^

الإعداد خطوة بخطوة

login block-for Login Enhancements

Router(config)# Exam PT ✔

الصيغة:

login block-for <block-seconds> attempts <max-tries> within <window-seconds>
login on-failure log
login on-success log

إيه اللي بنحطه مكان القيم:

  • <block-seconds> = عدد الثواني التي سيتم خلالها حظر أي محاولات تسجيل دخول جديدة بالكامل (Quiet Mode).
  • <max-tries> = أقصى عدد من المحاولات الفاشلة المسموح بها قبل فرض الحظر.
  • <window-seconds> = النافذة الزمنية لاحتساب المحاولات الفاشلة.

الشرح: الدفاع الأساسي ضد هجمات كسر وتخمين كلمات المرور (Brute-Force & Dictionary Attacks). إذا حاول مهاجم تخمين كلمة السر 3 مرات خلال 60 ثانية، يقفل الراوتر إمكانية تسجيل الدخول لمدة دقيقتين ويسجل الحادثة في الـ Syslog.

security passwords min-length Password Policy

Router(config)# Exam PT ✔

الصيغة:

security passwords min-length <number-of-characters>

الشرح: يمنع مهندسي الشبكة من تعيين كلمات مرور قصيرة وسهلة التخمين (مثل cisco أو 1234). يرفض الراوتر أي كلمة سر تقل عن الحد الأدنى المحدد (مثلاً 10 أحرف أو أكثر).

service password-encryption / enable secret Password Hashing Types

Router(config)# Exam PT ✔

الصيغة:

! تشفير كلمات السر العادية (Type 7 - ضعيف جداً)
service password-encryption

! استخدام دوال التجزئة القوية لكلمة سر وضع الـ Enable
enable secret <password>

! في أنظمة IOS الحديثة (تحديد خوارزمية التجزئة يدوياً):
enable algorithm-type {sha256 | scrypt} secret <password>

أنواع التشفير والتجزئة في سيسكو (فخ امتحاني مهم):

  • Type 0: نص واضح صريح غير مشفر (Plaintext) - خطر جداً.
  • Type 7: تشفير بسيط عبر خوارزمية Vigenère Cipher؛ يُفك في ثانية واحدة بأي موقع مجاني على الإنترنت! وظيفته فقط منع النظر من فوق الكتف (Shoulder Surfing).
  • Type 5: تجزئة عبر MD5 المستخدمة مع enable secret التقليدية.
  • Type 8: تجزئة عبر PBKDF2 مع SHA-256 (قوي وحديث).
  • Type 9: تجزئة عبر خوارزمية scrypt (الأقوى والأكثر مقاومة لهجمات المعالجات الرسومية GPU).

Zero Trust & SASE Architecture Modern Security Frameworks

Exam Core (v1.1) Theory

1. بنية انعدام الثقة (Zero Trust Architecture - ZTA):

  • المبدأ الجوهري: "لا تثق بأحد أبداً، وتحقق من كل شيء دائماً" (Never Trust, Always Verify).
  • في الشبكات التقليدية القديمة، كان يُفترض أن أي شخص داخل شبكة الشركة المحلية موثوق به. أما في Zero Trust، حتى لو كان الجهاز متصلاً بكابل LAN داخل مقر الشركة، لا يُمنح أي وصول إلا بعد المصادقة والتحقق من صحة الجهاز (Device Posture) وهويته في كل جلسة منفردة.
  • التقسيم المصغر (Micro-segmentation): عزل أجزاء الشبكة وخوادمها لتقييد الحركة الجانبية للمهاجم (Lateral Movement) إذا تمكن من اختراق نقطة واحدة.
  • مبدأ الصلاحيات الدنيا (Least Privilege): منح المستخدم أقل قدر ممكن من الصلاحيات والوصول المطلوب لإنجاز وظيفته فقط.

2. معمارية SASE و SSE:

  • SASE (Secure Access Service Edge): دمج قدرات شبكات الـ SD-WAN مع خدمات الأمان السحابية المتكاملة في منصة واحدة لحماية المستخدمين أينما وجدوا (في المكتب أو عن بُعد).
  • SSE (Security Service Edge): الجانب الأمني السحابي من SASE، ويشمل:
    • CASB (Cloud Access Security Broker): مراقبة وحماية استهلاك تطبيقات السحابة (SaaS).
    • SWG (Secure Web Gateway): فلترة تصفح الإنترنت وفحص التهديدات وحظر المواقع الضارة.
    • ZTNA (Zero Trust Network Access): إتاحة الوصول للتطبيقات الداخلية الخاصة بدون الحاجة لإنشاء نفق VPN كامل لكل الشبكة.
    • FWaaS (Firewall as a Service): جدار ناري مدار سحابياً (مثل Cisco Umbrella).

فحص الأعطال (Troubleshooting)

  • تم حظر تسجيل دخول المهندسين بسبب Brute-Force:
    1. إذا تكررت المحاولات الفاشلة ودخل الراوتر في الـ Quiet Mode، يمكنك الدخول حصرياً عبر منفذ الـ Console الفيزيائي إذا تم استثناؤه أو الانتظار حتى تنتهي مهلة الـ block-for.
    2. تأكد من فحص سجلات الـ Syslog لمعرفة الـ IP المصدر للهجوم وحظره عبر Access List.
  • جلسات الاتصال تقفل بسرعة أثناء العمل:
    1. افحص إعداد الـ exec-timeout تحت line vty و line con 0. إذا تم ضبط الثواني بدلاً من الدقائق بالخطأ (مثلاً exec-timeout 0 5 تعني 5 ثوانٍ فقط!)، قم بتعديلها إلى exec-timeout 5 0 (5 دقائق).
  • كلمات المرور مكشوفة كنص صريح في ملف الـ Config:
    1. اكتب أمر service password-encryption فوراً في وضع الكونفيج العام ليقوم الراوتر بتشفير جميع كلمات السر الحالية.
    2. استبدل أمر enable password بأمر enable secret فوراً.

أخطاء شائعة وفخاخ الامتحان

  • الفرق بين Type 7 و Type 5 و Type 8/9:
    • أمر service password-encryption ينشئ تشفير Type 7 فقط (ضعيف جداً ويمكن فكه بلمح البصر).
    • أمر enable secret ينشئ تجزئة Type 5 (MD5) أو Type 8/9 (قوية جداً ومحمية بخوارزميات تجزئة أحادية الاتجاه One-Way Hashing).
    • إذا كتبت enable password و enable secret معاً على نفس الجهاز، فإن الراوتر سيعتمد دائماً enable secret ويتجاهل enable password تماماً!
  • فخ الـ Delimiter في Banner MOTD:

    الحرف الذي تفتتح به الرسالة (مثل ^ أو # أو Z) هو الذي ينهيها. إذا كتبت نفس الحرف داخل نص الرسالة، سيعتبر الراوتر أن الرسالة انتهت عند تلك النقطة!

  • فخاخ الهندسة الاجتماعية (Social Engineering):
    • Phishing: رسائل بريد إلكتروني احتيالية عامة تستهدف أعداداً ضخمة من الموظفين.
    • Spear Phishing: هجوم بريد إلكتروني مخصص وموجه لشخص أو منصب محدد بدقة.
    • Whaling: هجوم يستهدف كبار المدراء التنفيذيين (C-Level Executives كالـ CEO).
    • Vishing: تصيد عبر المكالمات الصوتية الهاتفية (Voice Phishing).
    • Smishing: تصيد عبر الرسائل النصية القصيرة (SMS Phishing).
    • Watering Hole: اختراق موقع إلكتروني يتردد عليه موظفو الشركة المستهدفة بكثرة وإصابتهم من خلاله.
  • أجهزة الحماية المتقدمة (Cisco Security Portfolio):
    • NGFW (Next-Generation Firewall): مثل Cisco Firepower؛ يجمع بين جدار الحماية الحركي (Stateful Inspection) ونظام كشف الاختراق (IPS) والتحكم بالتطبيقات (AVC).
    • Cisco ISE (Identity Services Engine): خادم مركزي لنظام الـ AAA وتطبيق سياسات التحكم بالوصول إلى الشبكة (Network Access Control - NAC).
    • Cisco Umbrella: جدار حماية سحابي وحماية على مستوى استعلامات الـ DNS لحجب الروابط الخبيثة قبل الاتصال بها.
